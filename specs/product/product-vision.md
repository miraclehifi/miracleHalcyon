# miracleHalcyon

**最后更新**: 2026-10-10
**状态**: approved

---

## 1. 产品愿景

**一句话描述**: miracleHalcyon 是一个个人技术博客兼作品集，让作者打开浏览器就能写作发布，让读者获得快速舒适的阅读体验。

**背景**:
作者需要一个属于自己的技术写作阵地：既能沉淀技术文章，又能逐步展示个人项目、形成个人技术品牌。写作不应依赖本地开发环境，任何设备打开浏览器即可写作和发布。

**愿景**:
成为作者长期经营的个人技术主页——文章 + 作品集 + 读者互动，一站式呈现作者的技术形象。

---

## 2. 目标用户

| 用户角色 | 描述 | 核心诉求 | 使用频率 |
|----------|------|----------|----------|
| 读者 | 对作者技术文章和项目感兴趣的开发者 | 快速找到并舒适地阅读文章 | 不定期访问 |
| 作者（管理员） | 博客主人，唯一的写作者 | 随时随地写作、发布、修改文章 | 每周数次 |

**主要用户**: 读者（博客对外价值的承载者）

**次要用户**: 作者（唯一管理员，不开放注册）

---

## 3. 核心价值主张

**产品定位**: 阅读体验优先、可在线写作的个人技术博客。

**核心价值**:
1. **阅读体验好**: 加载快、排版舒适、代码块清晰、支持暗色模式与移动端
2. **随时随地写作**: 线上编辑器 + 实时预览 + 自动保存草稿，发布后立即可见

## 5. 全局约束

### 技术约束
- 框架：Astro 5（SSR 混合模式，`@astrojs/cloudflare` 适配器）+ React 19 + TypeScript
- 样式：Tailwind CSS 4 + `@tailwindcss/typography`
- 部署：Cloudflare（Pages / Workers）
- 数据存储：文章与元数据存 Cloudflare D1，图片存 Cloudflare R2
- 认证：单管理员账号密码登录，不开放注册
- UI 设计：Pencil，设计稿存放于 `specs/ui/`

### 业务约束
- 单作者博客，不支持多作者与权限分级
- 读者端无需登录即可阅读

### 合规要求
- 无特殊合规要求（不收集读者个人信息）
