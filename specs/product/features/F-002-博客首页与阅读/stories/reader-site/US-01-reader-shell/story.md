# 读者端外壳（顶栏、主题切换、返回、404）

**US ID**: US-01
**所属分组**: reader-site
**状态**: draft

---

## 1. User Story

**作为** 读者
**我想要** 统一的顶栏、主题切换和返回入口
**以便于** 在各页之间来回走，并按喜好的亮暗模式阅读

---

## 2. 验收标准

1. Given 我在读者端任意页面
   When 我查看顶栏
   Then 看到站点名 / 头像（回 `/`）、文章、书影音、摄影（新标签页）、GitHub（新标签页）、RSS、主题切换；当前所在栏目高亮，文章详情页与标签页高亮"文章"

2. Given 我在读者端任意页面
   When 我点击主题切换
   Then 在亮 / 暗 / 跟随系统三者间轮换；刷新或换页后保持选择，首屏不先闪成另一种主题

3. Given 我用 390 宽的手机访问
   When 我查看顶栏
   Then 文字项换成图标，GitHub / RSS 收起；所有可点区域 ≥ 44px

4. Given 我在首页以外的读者页
   When 我滚到页面底部
   Then 看到 `> cd ..`：文章详情回 `/posts`，其余回 `/`；首页不显示

5. Given 我访问不存在的路径（包括尚未上线的 `/media`、`/rss.xml`）
   When 页面加载
   Then 显示读者端 404 页，带回首页的入口

6. Given 我是读者
   When 我浏览读者端任意页面
   Then 看不到任何后台入口（作者直接访问 `/admin`）

---

## 3. 约束与假设

**约束**:
- 书影音（F-005）、RSS（F-004）照常显示，功能上线前为 404（2026-10-15 作者决定）
- 摄影站、GitHub 地址来自 `src/config/site.ts`
