# 文章图片展示与灯箱

**US ID**: US-10
**所属分组**: post-reading
**状态**: draft

---

## 1. User Story

**作为** 读者
**我想要** 看清文章中的图片，并能放大逐张浏览
**以便于** 图文类文章看得舒服

---

## 2. 验收标准

1. Given 正文有单图、宽图、组图、实况照片
   When 我阅读文章
   Then 显示与写文章页预览一致（宽图扩出、图注、网格 / 手风琴、实况悬停 / 长按播放、马赛克渐显）；图片预留宽高，加载时页面不跳动

2. Given 我点击任意图片（单图、网格单元格、手风琴当前展开项）
   When 点击
   Then 打开灯箱显示该图，带计数（如"3 / 12"）与图注

3. Given 灯箱已打开
   When 我按左右方向键、点左右按钮或在手机上左右滑动
   Then 在文中所有图片间切换；第一张 / 最后一张时对应方向不可用

4. Given 灯箱已打开
   When 我按 Esc、点关闭按钮、点遮罩或在手机上下滑
   Then 灯箱关闭，焦点回到打开它的图片

5. Given 灯箱中当前是实况照片
   When 我悬停或长按
   Then 播放视频，松开 / 移出回到静态图

6. Given 灯箱已打开
   When 我使用读屏或键盘
   Then 灯箱是名为"图片查看"的模态对话框，焦点在灯箱内循环，背景不滚动；减弱动效时没有层叠动画

---

## 3. 约束与假设

**约束**:
- 灯箱不做双指缩放 / 双击放大、从原位置缩放打开（DepthCarousel 3D 层叠）
