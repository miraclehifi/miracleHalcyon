# 三栏：同标签文章、阅读进度与目录

**US ID**: US-08
**所属分组**: post-reading
**状态**: draft

---

## 1. User Story

**作为** 读者
**我想要** 阅读时看到所处位置、能跳转章节，并发现相关文章
**以便于** 长文不迷路、读完有下一篇可看

---

## 2. 验收标准

1. Given 屏幕宽度 ≥ 1280
   When 我打开文章详情
   Then 左栏显示同标签文章，右栏显示阅读进度百分比与目录（h2 / h3）

2. Given 同标签文章
   When 左栏渲染
   Then 列出与本文至少共享一个标签的其他已发布文章，按共享标签数、发布时间降序，最多 8 篇；没有时不显示左栏

3. Given 我在滚动正文
   When 滚动
   Then 进度百分比从 0% 到 100% 变化；目录高亮当前所在章节

4. Given 我点击目录项
   When 点击
   Then 平滑滚动到对应标题，地址带对应 `#锚点`；减弱动效时直接跳转

5. Given 屏幕宽度 < 1280（含 390 手机）
   When 我阅读文章
   Then 侧栏收起：顶部细条显示进度；目录从浮动按钮打开（抽屉，点目录项后关闭）；同标签文章移到文末

6. Given 正文没有 h2 / h3
   When 页面渲染
   Then 不显示目录与目录按钮，进度照常显示
