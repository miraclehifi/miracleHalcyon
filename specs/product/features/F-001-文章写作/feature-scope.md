# 文章写作

**Feature ID**: F-001
**状态**: draft
**创建时间**: 2026-10-10

---

## 1. 概述

**一句话描述**: 作者登录后在浏览器中撰写、预览、保存草稿并发布 Markdown 文章，文章持久化到 D1，图片存入 R2。

**背景**:
产品核心价值之一是"随时随地写作"——写作不依赖本地开发环境。同时 F-001 产出的真实文章是 F-002（首页与阅读）的数据来源。

**目标用户**:
- 作者（唯一管理员）

---

## 2. 范围

### In Scope（本次要做的）

- **登录 / 登出**：管理员账号密码登录，登录失败限流；登出后会话失效
- **访问保护**：`/admin/**` 页面与所有写接口未登录不可访问
- **文章管理列表**：管理后台列出全部文章（含草稿），显示标题、状态、更新时间，可进入编辑、可新建、可删除
- **写文章页**：
  - 文章信息表单：标题、slug（由标题生成，可修改）、标签、摘要、发布日期、草稿/发布状态
  - Markdown 编辑区 + 实时预览（GFM、代码高亮）
  - 图片上传：粘贴或拖入图片 → 浏览器端压缩（长边 2560px、WebP）→ 上传至 R2 → 自动在光标处插入 Markdown 图片引用；预览区显示缩略图进度卡片，失败可重试
  - 实况照片：安卓动态照片（一个 JPEG 内嵌视频）识别上传，由工具栏"实况照片"开关决定是否保留视频（默认关闭）；iPhone / 苹果系统（HEIC、HEIC + MOV）不支持（2026-10-15 作者决定）
  - Afilmory 照片：粘贴 Afilmory 分享代码或照片页链接插入照片，图片不转存、直接引用外链存储（GitHub），显示效果与本站图片一致（含实况），只认 `site.ts` 登记的站点与存储前缀（2026-10-19 增量，[afilmory-photo-embed](../../../backlog/afilmory-photo-embed.md)）
  - 图片排版：宽图、组图网格、手风琴组图的写法与预览图片菜单；预览中的图片展示与读者端一致（`ArticleImage`、`LiveBadge`、`ImageGallery` 由本 Feature 实现）
  - 自动保存草稿：编辑停止后自动保存到服务端，显示保存状态；关闭页面重开后内容恢复
- **发布 / 更新 / 撤回**：将草稿发布为已发布状态；已发布文章可修改后更新；可撤回为草稿
- **文章数据模型**：定义 `post` Domain（供 F-002 读取已发布文章）

### Out of Scope（本次不做的）

- 读者端页面（首页、文章列表、文章详情、标签页）→ F-002
- 多作者、注册、找回密码、两步验证
- 文章版本历史 / 修订对比
- 定时发布
- 图片库管理（浏览/删除已上传图片）
- MDX（在文章中嵌入 React 组件）——在线存储的内容仅支持标准 Markdown（GFM）
- 评论、搜索、RSS → F-004

---

## 3. 边界定义

### 本 Feature 负责

- 管理员认证与会话
- 文章的创建、编辑、自动保存、发布、撤回、删除
- 图片（含实况视频）上传至 R2 并返回可访问 URL
- 图片 Markdown 扩展写法（宽图、实况、组图）的约定与渲染
- `post` Domain 数据模型与写入

### 本 Feature 不负责

- 已发布文章对读者的展示 → 由 F-002 负责
- 评论、搜索、RSS、SEO → 由 F-004 负责

### 依赖的其他 Feature

| Feature | 依赖内容 | 说明 |
|---------|----------|------|
| — | — | 首个 Feature；同时负责搭建项目骨架（Astro + Cloudflare 适配器 + D1/R2 绑定） |

### 被依赖情况

| Feature | 使用内容 | 说明 |
|---------|----------|------|
| F-002 | `post` Domain 的已发布文章（只读） | 文章列表页 `/posts`、详情页、标签页 |
| F-002 | Markdown 渲染规则 | 预览与读者端渲染须一致，渲染逻辑应可复用 |

**反向影响**: 无已有 Feature。发布/更新/撤回/删除文章需触发读者页重建（读者页构建时预渲染，F-002 实现 Deploy Hook 调用）。

## 5. 成功指标

| 指标 | 目标值 | 衡量方式 |
|------|--------|----------|
| 写作到可见 | 点击发布后 ≤ 10s 内文章状态可被读取 | 手动验证 |
| 草稿不丢失 | 停止输入 ≤ 3s 内自动保存；关闭页面重开内容完整恢复 | 验收测试 |
| 预览延迟 | 输入后预览更新 < 300ms（万字文章） | 手动验证 |
| 图片上传 | 5MB 以内图片上传并插入引用 < 5s | 手动验证 |
| 访问保护 | 未登录访问 `/admin/**` 及写接口 100% 被拒 | 验收测试 |
