# 发布、更新与撤回文章

**US ID**: US-08
**所属分组**: post-management
**状态**: draft

---

## 1. User Story

**作为** 作者
**我想要** 控制文章何时对读者可见
**以便于** 草稿打磨好再公开，发布后也能修改或撤回

---

## 2. 验收标准

1. Given 我在一篇草稿的写文章页
   When 我点击"发布"
   Then 文章状态变为"已发布"，读者可读取到该文章；若发布日期为空则设为今天

2. Given 标题为空或正文为空
   When 我点击"发布"
   Then 提示缺少的必填项，不发布

3. Given 一篇已发布文章有未发布修改
   When 我点击"发布更新"
   Then 读者看到的内容替换为最新内容，"未发布修改"标记消失

4. Given 一篇已发布文章
   When 我点击"撤回为草稿"并确认
   Then 文章对读者不可见，内容保留，状态变为"草稿"

5. Given 我点击发布/更新/撤回
   When 操作完成
   Then 读者页面缓存失效，10 秒内读者看到变化

6. Given 已发布文章没有未发布修改
   When 我查看写文章页
   Then "发布更新"按钮不可用

---

## 3. 约束与假设

**约束**:
- 读者端只能读到"已发布内容"，永远读不到草稿或未发布修改
