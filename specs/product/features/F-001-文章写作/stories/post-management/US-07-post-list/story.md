# 后台文章列表

**US ID**: US-07
**所属分组**: post-management
**状态**: draft

---

## 1. User Story

**作为** 作者
**我想要** 在后台看到我所有的文章及其状态
**以便于** 快速找到要继续写或修改的文章

---

## 2. 验收标准

1. Given 我已登录
   When 我进入后台首页
   Then 我看到文章列表：标题、状态（草稿 / 已发布 / 已发布有未发布修改）、标签、更新时间，按更新时间倒序

2. Given 列表中有文章
   When 我点击某篇文章
   Then 进入该文章的写文章页

3. Given 我在列表页
   When 我点击"新建文章"
   Then 进入空白的写文章页

4. Given 我在列表页
   When 我选择状态筛选（全部 / 草稿 / 已发布）或输入标题关键字
   Then 列表只显示匹配的文章

5. Given 还没有任何文章
   When 我进入列表页
   Then 显示空状态"还没有文章"与"写第一篇"按钮

6. Given 文章超过 20 篇
   When 我浏览列表
   Then 分页显示，每页 20 篇

---

## 3. 约束与假设

**假设**:
- 文章总量在千篇以内，无需复杂检索
