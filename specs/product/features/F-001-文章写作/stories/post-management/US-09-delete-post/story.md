# 删除文章

**US ID**: US-09
**所属分组**: post-management
**状态**: draft

---

## 1. User Story

**作为** 作者
**我想要** 删除不再需要的文章
**以便于** 保持后台整洁

---

## 2. 验收标准

1. Given 我在写文章页
   When 我点击"删除文章"
   Then 弹出确认框，显示文章标题，提示"删除后无法恢复"

2. Given 确认框已弹出
   When 我点击"确认删除"
   Then 文章被删除，回到列表页，列表中不再出现该文章；若曾发布，读者也无法再访问

3. Given 确认框已弹出
   When 我点击"取消"
   Then 文章保持不变

4. Given 我在后台列表
   When 我把某篇文章左滑到底，或左滑后点击"删除"
   Then 该行立即从列表移除，提示"已删除《标题》"并提供"撤销"；6 秒内未撤销则文章被删除，若曾发布读者也无法再访问

5. Given 列表删除后的撤销提示仍在
   When 我点击"撤销"
   Then 文章回到列表原来的位置，没有被删除

---

## 3. 约束与假设

**约束**:
- 删除文章不删除 R2 中的图片（图片管理不在本 Feature 范围）

**假设**:
- 列表删除的撤销靠前端延迟提交（6 秒后或离开页面时才发删除请求），不新增软删除
- 撤销期过后的误删恢复依赖 D1 Time Travel（详见 [全局 NFR](../../../../../nfr.md) §3），不提供回收站
