# 管理员登出

**US ID**: US-02
**所属分组**: admin-auth
**状态**: draft

---

## 1. User Story

**作为** 作者
**我想要** 在后台一键登出
**以便于** 在公共设备上写作后不留下可用的登录状态

---

## 2. 验收标准

1. Given 我已登录并在后台任意页面
   When 我点击"登出"
   Then 我回到登录页，会话 Cookie 被清除

2. Given 我已登出
   When 我用登出前的旧会话 Cookie 访问后台或调用写接口
   Then 被拒绝（页面跳转登录 / 接口返回 401）——会话在服务端已失效

---

## 3. 约束与假设

**约束**:
- 登出须使服务端会话失效，不能只删浏览器 Cookie
