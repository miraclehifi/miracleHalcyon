# 管理员登录

**US ID**: US-01
**所属分组**: admin-auth
**状态**: draft

---

## 1. User Story

**作为** 作者
**我想要** 用账号密码登录博客后台
**以便于** 只有我本人能写作和管理文章

---

## 2. 验收标准

1. Given 我未登录
   When 我访问任意 `/admin/**` 页面
   Then 我被跳转到登录页，登录成功后回到原先要访问的页面

2. Given 我在登录页
   When 我输入正确的账号和密码并提交
   Then 我进入后台文章列表页，浏览器获得 HttpOnly + Secure 的会话 Cookie

3. Given 我在登录页
   When 我输入错误的账号或密码
   Then 我看到"账号或密码错误"（不区分是账号错还是密码错）

4. Given 同一 IP 已连续登录失败 5 次
   When 15 分钟内再次尝试登录（即使密码正确）
   Then 我看到"尝试次数过多，请 15 分钟后再试"

5. Given 我未登录
   When 直接调用任意写接口
   Then 返回 401，数据不变

6. Given 我已登录且会话未过期（7 天内）
   When 我访问登录页
   Then 直接进入后台，无需再次登录

---

## 3. 约束与假设

**约束**:
- 仅一个管理员账号，凭据通过 Cloudflare Secrets 配置，不提供注册与改密页面
- 密码以不可逆哈希存储/比对（详见 [全局 NFR](../../../../../nfr.md) §2）

**假设**:
- 作者自行在部署配置中设置账号与密码哈希
