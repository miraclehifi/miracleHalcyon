## BH-01: 选中文字点击行内格式按钮，包裹 / 取消包裹

**SC-ID**: SC-TOOLBAR-01

```gherkin
Given 源码区内容为 "写作是思考"，我选中了 "思考"
When 我点击工具栏"加粗"
Then 内容变为 "写作是**思考**"
  And 选区仍是 "思考"
When 我再次点击"加粗"
Then 内容恢复为 "写作是思考"
```

斜体 `*`、行内代码 `` ` `` 同理；"链接"把选中文字变为 `[思考](url)`，并选中 `url` 方便直接输入。

## BH-02: 无选区点击行内格式按钮，插入成对标记并把光标放中间

**SC-ID**: SC-TOOLBAR-02

```gherkin
Given 源码区光标在行尾，没有选中文字
When 我点击"加粗"
Then 光标处插入 "****"
  And 光标位于两对 "**" 之间
```

## BH-03: 点击行级格式按钮，切换行首前缀（含多行选区）

**SC-ID**: SC-TOOLBAR-03

```gherkin
Given 源码区第 2–3 行为 "苹果" "香蕉"，选区跨这两行
When 我点击"列表"
Then 两行变为 "- 苹果" "- 香蕉"
When 我再次点击"列表"
Then 两行恢复为 "苹果" "香蕉"
```

前缀：二级标题 `## `、列表 `- `、任务列表 `- [ ] `、引用 `> `。一行已有另一种前缀时替换为新前缀（如 `- 苹果` 点"引用"变为 `> 苹果`）。

## BH-04: 格式快捷键执行命令并拦截浏览器默认行为

**SC-ID**: SC-TOOLBAR-04

```gherkin
Given 焦点在源码区，选中了 "思考"
When 我按 Mod+B
Then 结果与点击"加粗"相同
  And 浏览器默认行为（如书签栏、地址栏聚焦）未被触发
```

快捷键表：加粗 `Mod+B`、斜体 `Mod+I`、链接 `Mod+K`、行内代码 `Mod+E`、列表 `Mod+Shift+8`、引用 `Mod+Shift+.`。焦点不在源码区时（如标题输入框）不响应。

## BH-05: 输入法组字期间快捷键不触发

**SC-ID**: SC-TOOLBAR-05

```gherkin
Given 我正在用中文输入法组字（候选框打开）
When 我按下 Mod+B
Then 源码区内容不变
```

## BH-06: 格式命令可被原生撤销还原

**SC-ID**: SC-TOOLBAR-06

```gherkin
Given 我用"加粗"把 "思考" 变为 "**思考**"
When 我按 Mod+Z
Then 内容恢复为 "写作是思考"
```

## BH-07: 鼠标悬停 400ms 后显示提示与键帽

**SC-ID**: SC-TOOLBAR-07

```gherkin
Given 我在 Mac 桌面端打开写文章页
When 我把鼠标移到"加粗"按钮上并停留 400ms
Then 按钮下方出现提示 "加粗"，旁边键帽 "⌘B"
  And 停留不到 400ms 就移开时不出现提示
When 我把鼠标移到"任务列表"按钮上
Then 提示只有 "任务列表"，没有键帽
```

Windows / Linux 上键帽显示 `Ctrl B`。

## BH-08: 提示开着时移到相邻按钮，提示直接滑过去

**SC-ID**: SC-TOOLBAR-08

```gherkin
Given "加粗"的提示正显示
When 我把鼠标移到相邻的"斜体"
Then 不再等待 400ms，提示从"加粗"位置滑到"斜体"下方并换成 "斜体 ⌘I"
  And 页面上同一时间只有一个提示
Given 提示刚消失不到 300ms
When 我把鼠标移到另一个工具栏按钮
Then 提示立即出现，不再等待
```

## BH-09: 键盘聚焦立即显示提示，Esc 关闭

**SC-ID**: SC-TOOLBAR-09

```gherkin
Given 焦点在标题输入框
When 我按 Tab 把焦点移到工具栏"二级标题"
Then 立即显示提示 "二级标题"
  And 按钮的 aria-describedby 指向该提示（role="tooltip"）
When 我按 Esc
Then 提示关闭，焦点仍在"二级标题"
```

用鼠标点击按钮获得焦点时不显示（只响应 `:focus-visible`）。

## BH-10: 手机长按显示提示，不触发按钮操作

**SC-ID**: SC-TOOLBAR-10

```gherkin
Given 视口宽度 < 768px，键盘弹起，工具栏固定在键盘上方
When 我长按"加粗" 500ms
Then 按钮上方显示提示 "加粗"（不显示键帽）
  And 松手后源码区内容不变
When 我轻点"加粗"
Then 正常执行加粗，不显示提示
```

## BH-11: 顶栏与抽屉的图标按钮也有提示

**SC-ID**: SC-TOOLBAR-11

```gherkin
Given 视口宽度 < 768px（返回、设置只显示图标）
When 我长按顶栏返回按钮
Then 下方显示提示 "返回文章列表"
Given 桌面端设置抽屉已打开
When 我把鼠标移到抽屉右上角关闭按钮上 400ms
Then 下方显示提示 "关闭设置"
```

带文字的按钮（"← 文章"、"设置"、发布主按钮）不显示提示。
