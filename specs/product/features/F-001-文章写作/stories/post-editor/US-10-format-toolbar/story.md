# 格式工具栏与快捷键

**US ID**: US-10
**所属分组**: post-editor
**状态**: draft

---

## 1. User Story

**作为** 作者
**我想要** 用工具栏按钮或快捷键给 Markdown 加格式，并在悬停时看到按钮的作用和快捷键
**以便于** 不用记 Markdown 语法也能快速排版，用熟后只靠键盘写作

---

## 2. 验收标准

1. Given 我在源码区选中一段文字
   When 我点击工具栏"加粗"（或按 ⌘B / Ctrl+B）
   Then 选中文字两侧加上 `**`，选区仍是原来的文字；再操作一次则去掉 `**`

2. Given 光标在源码区某一行
   When 我点击"二级标题""列表""任务列表""引用"中的一个
   Then 该行行首加上对应前缀（`## `、`- `、`- [ ] `、`> `）；已有同样前缀时去掉

3. Given 我在源码区按下格式快捷键
   When 快捷键与浏览器默认行为相同（如 ⌘B、⌘K）
   Then 只执行格式命令，不触发浏览器默认行为；输入法组字期间不触发

4. Given 我在桌面端把鼠标移到工具栏按钮上
   When 停留 400ms
   Then 按钮下方出现提示，显示按钮名称；有快捷键的同时显示键帽（Mac 显示 ⌘，其他系统显示 Ctrl）

5. Given 工具栏某个提示正显示（或刚消失不到 300ms）
   When 我把鼠标移到相邻按钮
   Then 提示不再等待，直接滑到新按钮并换成新名称

6. Given 我用 Tab 键聚焦工具栏按钮
   When 焦点落在按钮上
   Then 立即显示提示；按 Esc 关闭提示且焦点不变

7. Given 我在手机上
   When 长按工具栏按钮 500ms
   Then 按钮上方显示提示（不显示键帽），松手后不触发该按钮的操作

---

## 3. 约束与假设

**约束**:
- 快捷键：加粗 `Mod+B`、斜体 `Mod+I`、链接 `Mod+K`、行内代码 `Mod+E`、列表 `Mod+Shift+8`、引用 `Mod+Shift+.`（`Mod` = Mac 的 ⌘ / 其他系统的 Ctrl）；二级标题、任务列表、插入图片无快捷键
- 格式命令只改源码区文本，可被浏览器原生撤销（⌘Z / Ctrl+Z）还原
- 提示与按钮的 `aria-label` 同名；提示只做补充说明，不代替按钮的可访问名称

**假设**:
- "插入图片"的上传流程见 US-05，本 US 只覆盖它的提示
