# 图片上传

**US ID**: US-05
**所属分组**: post-editor
**状态**: draft

---

## 1. User Story

**作为** 作者
**我想要** 直接把截图粘贴或拖进正文
**以便于** 不用手动上传图片、复制链接

---

## 2. 验收标准

1. Given 我在正文编辑区
   When 我粘贴剪贴板中的图片，或拖入图片文件
   Then 光标处先插入占位文本"上传中…"，上传成功后替换为 `![文件名](图片URL)`，预览区显示图片

2. Given 我点击工具栏"插入图片"
   When 我选择本地图片
   Then 行为同上

3. Given 图片超过 5MB
   When 我尝试上传
   Then 提示"图片不能超过 5MB"，不上传，占位文本被移除

4. Given 文件不是 png/jpg/webp/gif（例如 svg、pdf）
   When 我尝试上传
   Then 提示"仅支持 png、jpg、webp、gif"，不上传

5. Given 上传过程中网络失败
   When 上传失败
   Then 占位文本被移除并提示"上传失败，请重试"，正文其他内容不受影响

6. Given 我一次拖入多张图片
   When 上传
   Then 每张图片按顺序各自插入引用

---

## 3. 约束与假设

**约束**:
- 图片存储于 R2，文件名使用随机/哈希命名，避免覆盖与路径猜测
- 上传接口需登录
