# 自动保存草稿

**US ID**: US-06
**所属分组**: post-editor
**状态**: draft

---

## 1. User Story

**作为** 作者
**我想要** 写作内容自动保存
**以便于** 意外关闭页面或断网时不丢失已写内容

---

## 2. 验收标准

1. Given 我在写文章页修改了标题、信息或正文
   When 我停止输入 2 秒
   Then 内容自动保存到服务端，状态栏显示"已保存 · HH:mm"

2. Given 保存进行中
   When 状态栏刷新
   Then 显示"保存中…"；有未保存修改时显示"未保存"

3. Given 我写了内容但网络断开
   When 自动保存失败
   Then 状态栏显示"保存失败，将自动重试"，内容同时暂存在浏览器本地；网络恢复后自动重新保存

4. Given 我关闭页面后重新打开这篇文章
   When 页面加载
   Then 我看到最后一次保存的内容；若浏览器本地暂存比服务端更新，提示"发现未同步的本地内容，是否恢复？"

5. Given 新建文章尚未保存过且标题为空
   When 我开始输入正文
   Then 自动保存仍会创建草稿（标题暂为"无标题"），避免内容丢失

6. Given 文章是已发布状态
   When 自动保存触发
   Then 只保存为该文章的"未发布修改"，读者看到的仍是上次发布的版本，直到我点击"发布更新"（见 US-08）

7. Given 有未保存修改
   When 我尝试关闭或离开页面
   Then 浏览器弹出离开确认

---

## 3. 约束与假设

**约束**:
- 自动保存不得改变文章的发布状态

**假设**:
- 单作者，暂不处理多标签页同时编辑同一篇文章的冲突（后写覆盖）
