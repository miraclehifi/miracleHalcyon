# 书影音 — Feature NFR

**最后更新**: 2026-10-21

> 全局 NFR 见 [nfr.md](../../nfr.md)，本文件只列 F-005 特有要求。

| 类别 | 要求 |
|------|------|
| 识别接口防 SSRF | 服务端只请求豆瓣域名（`douban.com` 及其子域；封面只限 `*.doubanio.com`）；不跟随任何重定向（3xx 视为失败）；不接受任意 URL |
| 识别接口限时 | 单次识别服务端总耗时 ≤ 8s，超时按"链接打不开"失败返回 |
| 封面转存 | 识别时服务端下载封面（只限豆瓣图片域名），按文件头校验为 jpg / png / webp、≤ 5MB，不符合则识别结果不含封面并提示；保存接口不接受外部 URL，只收文件（ADR-011） |
| 鉴权 | 识别、条目写接口均需管理员会话 + Origin 校验（沿用全局） |
| 读者页 | `/media` 构建时预渲染；条目写操作后触发重建，P95 ≤ 5 分钟可见（沿用全局） |
