# 粘贴豆瓣链接识别填表

**US ID**: US-02
**所属分组**: media-shelf
**状态**: draft

---

## 1. User Story

**作为** 作者
**我想要** 在录入表单里粘贴豆瓣分享链接或分享文字，点一下就自动填好条目信息
**以便于** 不用手抄标题、作者、年份和找封面，录入一条只需补状态、评分和日期

---

## 2. 验收标准

1. Given 我在录入表单
   When 我看表单顶部
   Then 有多行识别框，占位文字"粘贴豆瓣分享链接或分享文字，自动识别条目信息"，右侧"识别"按钮，框内有清空按钮；粘贴后不自动识别

2. Given 我粘贴了一个豆瓣条目链接（如 `https://book.douban.com/subject/1234567/`）
   When 我点"识别"
   Then 表单的分类、标题、封面、作者 / 导演 / 开发商、年份、豆瓣链接被填入，被填入的字段短暂高亮；识别框下方提示"已识别：标题、封面、作者……"

3. Given 我粘贴了豆瓣 App 分享出来的链接或整段文字（如 `https://www.douban.com/doubanapp/dispatch/movie/37501131`）
   When 我点"识别"
   Then 从文字中提取第一个豆瓣链接直接识别，结果同第 2 条

4. Given 我已经手动选好状态、评分、标记日期、填了短评
   When 我识别
   Then 这四项保持不变；只有识别到的字段被覆盖，没识别到的字段保持原值

5. Given 识别结果缺少某些字段（例如年份）
   When 识别完成
   Then 缺的字段不改动，提示"未识别：年份，请手动填写"

6. Given 我粘贴的内容里没有豆瓣链接 / 链接打不开或超时 / 页面解析不出条目
   When 我点"识别"
   Then 分别提示"不是豆瓣链接""链接打不开""解析不出条目信息"，表单保持原样，可全部手填保存

7. Given 识别进行中
   When 我继续在表单中输入
   Then 表单不锁定，"识别"按钮显示加载状态且不可重复点击

8. Given 这个豆瓣条目已经录入过
   When 识别完成
   Then 提示"这条已经录入过"，并提供"去编辑"入口，点击打开已有条目的编辑表单；当前表单不填入识别结果

9. Given 豆瓣条目有封面
   When 识别完成
   Then 表单显示封面预览（由服务端下载，不直接加载豆瓣图片）；保存后封面存入 R2，读者端只引用 R2 地址；封面下载失败时封面保持原值，提示"未识别：封面，可手动上传"；**识别出的分类为"游戏"时不下载豆瓣封面**，封面保持原值，提示"未识别：封面，游戏封面请粘贴 IGDB 图片链接"（游戏封面只用 IGDB 链接，[ADR-013](../../../../../../engineering/features/F-005-书影音/architecture/adr/ADR-013-game-cover-igdb-link.md)）

10. Given 识别推断的分类是"剧集"
    When 我觉得应该是"电影"
    Then 我可以在表单中把分类改成"电影"再保存

11. Given 我识别过一次
    When 我清空识别框，粘贴另一个链接再识别
    Then 新结果覆盖上一次识别填入的字段

---

## 3. 约束与假设

**约束**:
- 只解析条目本身：标题、封面、作者 / 导演 / 开发商、年份、分类、豆瓣链接与条目 ID；不解析状态、评分、日期、短评
- 分类推断：书 → 书，带"漫画"标签的书 → 漫画；电影（含动画电影）→ 电影；电视剧（含动画剧集）→ 剧集；游戏 → 游戏，桌游按平台 / 类型字段识别（字段待 spike 确认）
- 识别由服务端完成，只请求豆瓣白名单域名，单次 ≤ 8s（Feature NFR）
- 编辑已有条目时同样可用识别框

**假设**:
- 豆瓣移动端接口在 Worker 出口 IP 下可用（plan-tasks 第一个 spike 验证）；若不可用，本 US 降级为"识别总是失败、全部手填"，并回到作者决策
