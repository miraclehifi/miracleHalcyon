# 后台管理书影音条目

**US ID**: US-01
**所属分组**: media-shelf
**状态**: draft

---

## 1. User Story

**作为** 作者
**我想要** 在后台录入、编辑、隐藏、删除我读过、看过、玩过以及正在进行的条目
**以便于** 维护书影音记录，并让读者页随之更新

---

## 2. 验收标准

1. Given 我已登录后台
   When 我点后台顶栏的"书影音"
   Then 进入 `/admin/media`，看到条目列表，按分类 Tab 切换（书 / 漫画 / 电影 / 剧集 / 游戏 / 桌游），默认"书"；每行显示封面缩略图、标题、作者 / 导演 / 开发商、状态、评分、标记日期，隐藏的条目带"已隐藏"标记；进行中的置顶，其余按标记日期倒序

2. Given 我在条目列表
   When 我点"新增条目"
   Then 打开录入表单，分类默认为当前 Tab，状态默认"已完成"，标记日期默认今天，其余为空

3. Given 我在录入表单填写了分类、标题、状态、标记日期，其余留空
   When 我点"保存"
   Then 条目保存成功，回到列表并能看到它；读者页触发重建

4. Given 表单缺少标题、或评分不在 1–5、或年份不是 4 位数字
   When 我点"保存"
   Then 不保存，对应字段下提示原因，已填内容保留

5. Given 我在录入表单
   When 我选择一张本地图片作为封面
   Then 表单显示封面预览；保存后封面存入 R2（格式与大小限制同 Feature NFR）

6. Given 一个"在读"的条目
   When 我编辑它，把状态改成"已完成"、填上评分和短评并保存
   Then 列表中它不再置顶，按标记日期排序；读者页触发重建

7. Given 一个已显示的条目
   When 我点"隐藏"
   Then 它带"已隐藏"标记留在后台列表，读者页不再显示；再点"取消隐藏"恢复显示；两次操作都触发重建

8. Given 一个条目
   When 我点"删除"并在二次确认中确认
   Then 条目从列表消失，它的 R2 封面一并删除；读者页触发重建

9. Given 我编辑条目时换了封面
   When 保存
   Then 新封面生效，旧封面从 R2 删除

10. Given 我未登录
    When 访问 `/admin/media` 或调用条目写接口
    Then 页面跳转登录，接口返回 401（同其他后台页）

11. Given 我在录入表单，分类为"游戏"
    When 我选择平台、在"封面链接（IGDB）"粘贴 images.igdb.com 的封面图片地址并保存
    Then 表单显示平台下拉（PS5 / PS4 / Switch / Switch 2 / Steam，新增时默认 PS5）和封面链接输入框，不显示上传按钮；预览按原图比例显示；保存后条目记录平台、IGDB 大图地址（统一为 t_1080p）与大图宽高；地址格式不对或打不开时不保存并提示原因

---

## 3. 约束与假设

**约束**:
- 状态只有"已完成""进行中"两种，按分类显示动词：书 / 漫画"读过 / 在读"，电影 / 剧集"看过 / 在看"，游戏 / 桌游"玩过 / 在玩"
- 评分为 1–5 整数，可空；短评纯文本，不渲染 Markdown
- 标记日期精确到日；进行中的条目也有标记日期（开始日期）
- 豆瓣链接字段只由识别（US-02）写入，表单中只读展示，可清除
- 游戏必须有平台，其他分类没有平台；游戏封面只用 IGDB 链接、不上传图片，其他分类只上传图片（[ADR-013](../../../../../../engineering/features/F-005-书影音/architecture/adr/ADR-013-game-cover-igdb-link.md)）
- 写操作沿用会话 + Origin 校验；触发重建沿用 Deploy Hook

**假设**:
- 条目总量在 1,000 条量级，后台列表一次加载当前分类全部条目，不分页
