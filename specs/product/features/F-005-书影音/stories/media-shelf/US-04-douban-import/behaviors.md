## BH-01: 打开导入面板，带出上次用过的 ID

**SC-ID**: SC-IMPORT-01

```gherkin
Given 我已登录，在后台书影音列表页
  And 服务端记录的豆瓣 ID 为 "189806038"，6 个类别都已完成同步，最近一次在 2026-10-23 21:30
When 我点"从豆瓣导入"
Then 打开导入面板，ID 输入框已填 "189806038"
  And 输入框下方说明"豆瓣个人主页 douban.com/people/ID/ 中的 ID"
  And 主按钮"同步新标记"、次要按钮"全量导入"，显示"上次同步：2026-10-23 21:30"
Given 服务端没有任何同步记录
When 我点"从豆瓣导入"
Then ID 输入框为空，只有"全量导入"按钮，不显示上次同步时间
```

## BH-02: ID 为空或格式不对时不能开始

**SC-ID**: SC-IMPORT-02

```gherkin
Given 导入面板已打开
When ID 输入框为空
Then "全量导入"与"同步新标记"都不可用
When 我输入 "abc/../x"
Then 输入框下方提示"用户 ID 只能包含字母、数字、下划线、点和短横线"
  And 两个导入按钮都不可用
```

## BH-03: 导入影视：电影 / 剧集分类，带状态、评分、日期、短评

**SC-ID**: SC-IMPORT-03

```gherkin
Given 豆瓣用户的影视"看过"中有电影《奥德赛》（type=movie，2026，导演 克里斯托弗·诺兰，评 4 星，标记于 2026-09-01 20:10:00，短评"好看"）
  And 影视"在看"中有剧集《百年孤独 第二季》（type=tv，未评分）
When 导入完成
Then 新增电影条目《奥德赛》：状态 已完成、评分 4、标记日期 2026-09-01、短评"好看"、年份 2026、导演 克里斯托弗·诺兰、豆瓣链接 https://movie.douban.com/subject/{id}/
  And 新增剧集条目《百年孤独 第二季》：状态 进行中、评分为空
```

## BH-04: 导入书：漫画判定、作者去国籍、年份取出版日期

**SC-ID**: SC-IMPORT-04

```gherkin
Given 豆瓣用户的书"读过"中有《霍乱时期的爱情》（作者"[哥伦比亚] 加西亚·马尔克斯"，出版日期"2012-9-1"）
  And 有一本条目标签含"漫画"的书
When 导入完成
Then 《霍乱时期的爱情》分类为 书、作者"加西亚·马尔克斯"、年份 2012
  And 带"漫画"标签的那本分类为 漫画
```

## BH-05: 导入游戏：平台映射、桌游判定、不下载封面

**SC-ID**: SC-IMPORT-05

```gherkin
Given 豆瓣用户的游戏"玩过"中有《羊蹄山之魂》，我标记的平台为 PS5
  And 有一款我标记平台为 PC 的游戏
  And 有一款我未标记平台的游戏
  And 有一款类型含"桌游"的游戏
When 导入完成
Then 《羊蹄山之魂》分类 游戏、平台 PS5、年份取发行日期、开发商取自豆瓣游戏详情
  And PC 游戏平台为 Steam；未标记平台的游戏平台为 PS5
  And 类型含"桌游"的条目分类为 桌游
  And 所有游戏条目都没有封面，服务端没有请求它们的豆瓣封面
```

## BH-06: 只导入已完成和进行中，跳过想看

**SC-ID**: SC-IMPORT-06

```gherkin
Given 豆瓣接口返回的标记里混有 status=mark（想看）的条目
When 导入完成
Then 想看的条目没有写入书影音
  And 汇总里不计入新增或失败
```

## BH-07: 未评分的标记评分为空

**SC-ID**: SC-IMPORT-07

```gherkin
Given 一条"看过"标记的 rating 为 null
When 它被导入
Then 条目评分为空（不是 0）
```

## BH-08: 已有相同豆瓣 ID 的条目被覆盖，隐藏与封面不变

**SC-ID**: SC-IMPORT-08

```gherkin
Given 书影音里已有豆瓣 ID 30513783 的条目：状态 进行中、评分为空、已隐藏、有 R2 封面
  And 豆瓣标记为 看过、5 星、短评"神作"
When 导入完成
Then 该条目状态改为 已完成、评分 5、短评"神作"、标记日期改为豆瓣的日期
  And 仍为隐藏，封面不变，未重新下载封面
  And 书影音中豆瓣 ID 30513783 的条目只有一条，计入"更新"
```

## BH-09: 豆瓣缺失的字段保留原值

**SC-ID**: SC-IMPORT-09

```gherkin
Given 已有游戏条目开发商为"Sucker Punch"、IGDB 封面已填、平台 PS4
  And 这次导入时该游戏的豆瓣详情请求失败，标记里也没有平台
When 导入到这条
Then 开发商仍为"Sucker Punch"、IGDB 封面不变、平台仍为 PS4
  And 其他豆瓣有值的字段（标题、状态、评分、日期、短评）被覆盖
```

## BH-10: 非游戏封面下载存入 R2，失败不影响导入

**SC-ID**: SC-IMPORT-10

```gherkin
Given 一条新的电影标记有封面地址
  And 另一条新的书标记的封面下载返回 418
When 导入完成
Then 电影条目有 R2 封面，读者端只引用站内地址
  And 书条目照常导入、没有封面，汇总"封面失败 1"
```

## BH-11: 分页：单页返回少于请求条数时继续翻页直到总数

**SC-ID**: SC-IMPORT-11

```gherkin
Given 豆瓣影视"看过"总数 45，按每页 20 请求
  And 第一页只返回 19 条（有失效条目被过滤）
When 导入进行
Then 依次请求 start=0、20、40，不重复也不遗漏任何一页
  And 进度总数按豆瓣返回的 total 计算
```

## BH-12: 进度显示与结束汇总

**SC-ID**: SC-IMPORT-12

```gherkin
Given 我点了"全量导入"或"同步新标记"
When 导入进行中
Then 面板显示当前类别和进度，如"影视 · 看过 40 / 614"，ID 输入框与两个导入按钮不可用，显示"停止"
When 全部类别导入完成
Then 面板显示"导入完成：新增 X、更新 Y、失败 Z、封面失败 W"
  And 后台列表刷新显示导入后的条目
When 进行的是"同步新标记"且某类有水位
Then 该类进度显示已处理条数而不是总数，如"影视 · 看过 已同步 3 条"；结束时汇总前缀为"同步完成："
  And 汇总下方显示新的"上次同步"时间
```

## BH-13: 单条失败不中断整批，汇总列出失败条目

**SC-ID**: SC-IMPORT-13

```gherkin
Given 一页 20 条标记中有 1 条缺少标题
When 这一页被导入
Then 其余 19 条正常写入
  And 汇总的失败列表显示该条的豆瓣 ID 与原因"解析不出条目信息"
```

## BH-14: 中途出错后重新导入不产生重复条目

**SC-ID**: SC-IMPORT-14

```gherkin
Given 上次全量导入在影视第 3 页时网络断开，已写入 40 条
When 我再次点"全量导入"或"同步新标记"
Then 影视·看过从第一页重新同步（该类没有水位）
  And 已写入的 40 条按 BH-08 覆盖，每个豆瓣 ID 只有一条条目
```

## BH-15: 导入中可停止，已导入保留

**SC-ID**: SC-IMPORT-15

```gherkin
Given 导入进行中，已处理 60 条
When 我点"停止"
Then 当前这一页处理完后不再请求下一页
  And 面板显示"已停止：新增 X、更新 Y……"
  And 已写入的条目保留
```

## BH-16: 整次导入只触发一次重建

**SC-ID**: SC-IMPORT-16

```gherkin
Given 一次导入共处理了多页
When 导入完成或被停止，且至少写入了一条
Then 只触发一次 Deploy Hook
  And 逐页导入的过程中不触发 Deploy Hook
When 一条也没写入（如用户不存在）
Then 不触发 Deploy Hook
```

## BH-17: 用户不存在

**SC-ID**: SC-IMPORT-17

```gherkin
Given 豆瓣对该 ID 的标记接口返回 404
When 我点"全量导入"
Then 面板提示"豆瓣上找不到这个用户"
  And 没有写入任何条目，没有触发重建
```

## BH-18: 标记不公开或需登录

**SC-ID**: SC-IMPORT-18

```gherkin
Given 豆瓣标记接口返回 403，或要求登录
When 我点"全量导入"
Then 面板提示"豆瓣标记未公开或需要登录，无法导入"
  And 没有写入任何条目
```

## BH-19: 豆瓣请求失败 / 超时

**SC-ID**: SC-IMPORT-19

```gherkin
Given 导入进行到某一页时，豆瓣标记列表请求超时或返回 5xx / 3xx
When 这一页请求失败
Then 面板停止导入，提示"豆瓣暂时无法访问，已导入的条目已保存，可稍后重新导入"
  And 已写入的条目保留；若已写入至少一条，触发一次重建
```

## BH-20: 用户 ID 不合法时接口拒绝且不发外部请求

**SC-ID**: SC-IMPORT-20

```gherkin
Given 我已登录
When 直接调用导入接口，用户 ID 为 "../user/1" 或超过 64 个字符
Then 返回 400 VALIDATION_FAILED
  And 服务端没有向豆瓣发出任何请求
```

## BH-21: 未登录或跨站调用导入接口被拒

**SC-ID**: SC-IMPORT-21

```gherkin
Given 我未登录，或请求来自其他站点
When 调用导入接口
Then 返回 401 / 403，与其他后台写接口一致
  And 没有写入任何条目
```

## BH-22: 同步新标记：翻到水位之前的标记即停止

**SC-ID**: SC-IMPORT-22

```gherkin
Given 影视·看过的水位为 "2026-10-18 08:25:08"
  And 豆瓣影视看过第一页依次是 3 条晚于水位的新标记、1 条恰为水位的标记、16 条更早的标记
When 我点"同步新标记"
Then 只处理前 4 条（3 条新增，水位那条按 BH-08 覆盖）
  And 该类别不再请求第二页
  And 水位前移到第一条新标记的时间
```

## BH-23: 同步新标记：与水位同一秒的标记仍处理

**SC-ID**: SC-IMPORT-23

```gherkin
Given 水位为 "2026-10-18 08:25:08"，豆瓣有两条标记时间都是 "2026-10-18 08:25:08"，其中一条上次同步时还没出现
When 我点"同步新标记"
Then 两条都被处理（已有的覆盖、没有的新增），不会漏掉同一秒的标记
```

## BH-24: 水位只在类别完整同步后前移

**SC-ID**: SC-IMPORT-24

```gherkin
Given 影视·看过的水位为 T0
When 同步新标记时影视·看过翻完（到达水位），随后在书·读过第 2 页点了"停止"
Then 影视·看过的水位前移到本次第一条标记的时间
  And 书·读过的水位保持不变，同步时间不更新
When 全量导入中途某一页返回 FETCH_FAILED
Then 出错的类别水位不变；之前已完整翻完的类别水位已前移
```

## BH-25: 没有水位的类别按全量处理

**SC-ID**: SC-IMPORT-25

```gherkin
Given 影视两类有水位，书和游戏四类没有水位（上次全量导入在书·读过中断）
When 我点"同步新标记"
Then 影视两类只同步水位之后的标记
  And 书、游戏四类从第一页翻到最后一页
  And 翻完后这四类也有了水位
```

## BH-26: 在看改看过后同步新标记更新为已完成

**SC-ID**: SC-IMPORT-26

```gherkin
Given 本站已有剧集《百年孤独 第二季》状态 进行中
  And 我在豆瓣把它从"在看"改为"看过"，豆瓣看过列表最前出现这条，标记时间晚于水位
When 我点"同步新标记"
Then 该条目状态改为 已完成，标记日期改为新的标记日期，计入"更新"
```

## BH-27: 换豆瓣 ID 后水位按新 ID 计

**SC-ID**: SC-IMPORT-27

```gherkin
Given 豆瓣 ID "189806038" 的 6 个类别都有水位
When 我把 ID 改为 "ahbei" 并点"同步新标记"
Then 6 个类别都按全量处理
  And 同步完成后服务端记录的 ID 变为 "ahbei"，下次打开面板带出 "ahbei"
  And "189806038" 的水位保留，改回原 ID 时仍可增量同步
```
