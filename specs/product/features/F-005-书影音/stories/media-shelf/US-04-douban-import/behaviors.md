## BH-01: 打开导入面板，带出上次用过的 ID

**SC-ID**: SC-IMPORT-01

```gherkin
Given 我已登录，在后台书影音列表页
  And 服务端记录的豆瓣 ID 为 "189806038"；电影、书、游戏、桌游最近一次在 2026-10-23 21:30 同步过，漫画在 2026-10-20 09:05 同步过，剧集从未同步
When 我点"从豆瓣导入"
Then 打开导入面板，ID 输入框已填 "189806038"
  And 输入框下方说明"豆瓣个人主页 douban.com/people/ID/ 中的 ID"
  And "导入类别"六个勾选项按 电影、剧集、书 / 漫画、游戏、桌游 两行排列，全部默认勾上
  And 每个勾选项文字旁小字显示该类别的上次同步：电影 "10-23 21:30"、剧集 "未同步"、漫画 "10-20 09:05"……
  And 主按钮"同步新标记"、次要按钮"全量导入"
Given 服务端没有任何同步记录
When 我点"从豆瓣导入"
Then ID 输入框为空，六个类别都勾上、都显示"未同步"，只有"全量导入"按钮
When 我取消勾选几个类别后关闭面板，再次打开
Then 六个类别又全部勾上（勾选不保存）
```

## BH-02: ID 为空、格式不对或一个类别都没选时不能开始

**SC-ID**: SC-IMPORT-02

```gherkin
Given 导入面板已打开
When ID 输入框为空
Then "全量导入"与"同步新标记"都不可用
When 我输入 "abc/../x"
Then 输入框下方提示"用户 ID 只能包含字母、数字、下划线、点和短横线"
  And 两个导入按钮都不可用
When ID 合法，但六个类别都没勾
Then 类别下方提示"至少选择一个类别"，两个导入按钮都不可用
When 我再勾上任意一个类别
Then 提示消失，按钮恢复可用
```

## BH-11: 分页：单页返回少于请求条数时继续翻页直到总数

  And 第一页只返回 19 条（有失效条目被过滤）
When 导入进行

## BH-12: 进度显示与结束汇总

**SC-ID**: SC-IMPORT-12

```gherkin
Given 我勾选了"电影""书""漫画"，点了"全量导入"或"同步新标记"
When 导入进行中
Then 依次进行 影视·看过 → 影视·在看 → 书·读过 → 书·在读 四步（游戏一类没勾，不请求）
  And 面板显示当前步骤和进度，如"影视 · 看过 40 / 614"，ID 输入框、类别勾选与两个导入按钮不可用，显示"停止"
When 四步都完成
Then 面板显示"导入完成：新增 X、更新 Y、失败 Z、封面失败 W"
  And 后台列表刷新显示导入后的条目
When 进行的是"同步新标记"且这一步按增量处理
Then 该步进度显示已处理条数而不是总数，如"影视 · 看过 已同步 3 条"；结束时汇总前缀为"同步完成："
  And 各勾选类别旁的上次同步时间更新为刚才的时间
```

## BH-13: 单条失败不中断整批，汇总列出失败条目

**SC-ID**: SC-IMPORT-13

```gherkin
Given 一页 20 条标记中有 1 条缺少标题
When 这一页被导入
Then 其余 19 条正常写入
  And 汇总的失败列表显示该条的豆瓣 ID 与原因"解析不出条目信息"
```

## BH-14: 中途出错后重新导入不产生重复条目

**SC-ID**: SC-IMPORT-14

```gherkin
Given 上次全量导入在影视·看过第 3 页时网络断开，已写入 40 条
When 我再次点"全量导入"或"同步新标记"
Then 影视·看过从第一页重新同步（勾选的电影、剧集在这一步的水位都没有前移）
  And 已写入的 40 条按 BH-08 覆盖，每个豆瓣 ID 只有一条条目
```

## BH-15: 导入中可停止，已导入保留

**SC-ID**: SC-IMPORT-15

```gherkin
Given 导入进行中，已处理 60 条
When 我点"停止"
Then 当前这一页处理完后不再请求下一页
  And 面板显示"已停止：新增 X、更新 Y……"
  And 已写入的条目保留
```

## BH-16: 整次导入只触发一次重建

**SC-ID**: SC-IMPORT-16

```gherkin
Given 一次导入共处理了多页
When 导入完成或被停止，且至少写入了一条
Then 只触发一次 Deploy Hook
  And 逐页导入的过程中不触发 Deploy Hook
When 一条也没写入（如用户不存在）
Then 不触发 Deploy Hook
```

## BH-17: 用户不存在

**SC-ID**: SC-IMPORT-17

```gherkin
Given 豆瓣对该 ID 的标记接口返回 404
When 我点"全量导入"
Then 面板提示"豆瓣上找不到这个用户"
  And 没有写入任何条目，没有触发重建
```

## BH-18: 标记不公开或需登录

**SC-ID**: SC-IMPORT-18

```gherkin
Given 豆瓣标记接口返回 403，或要求登录
When 我点"全量导入"
Then 面板提示"豆瓣标记未公开或需要登录，无法导入"
  And 没有写入任何条目
```

## BH-19: 豆瓣请求失败 / 超时

**SC-ID**: SC-IMPORT-19

```gherkin
Given 导入进行到某一页时，豆瓣标记列表请求超时或返回 5xx / 3xx
When 这一页请求失败
Then 面板停止导入，提示"豆瓣暂时无法访问，已导入的条目已保存，可稍后重新导入"
  And 已写入的条目保留；若已写入至少一条，触发一次重建
```

## BH-20: 用户 ID 或类别不合法时接口拒绝且不发外部请求

**SC-ID**: SC-IMPORT-20

```gherkin
Given 我已登录
When 直接调用导入接口，用户 ID 为 "../user/1" 或超过 64 个字符
Then 返回 400 VALIDATION_FAILED
  And 服务端没有向豆瓣发出任何请求
When 直接调用影视的导入接口，类别为空、含不属于影视的 "book"、含未知的 "music" 或重复
Then 同样返回 400 VALIDATION_FAILED，没有向豆瓣发出任何请求
```

## BH-21: 未登录或跨站调用导入接口被拒

**SC-ID**: SC-IMPORT-21

```gherkin
Given 我未登录，或请求来自其他站点
When 调用导入接口
Then 返回 401 / 403，与其他后台写接口一致
  And 没有写入任何条目
```

## BH-22: 同步新标记：翻到水位之前的标记即停止

**SC-ID**: SC-IMPORT-22

```gherkin
Given 电影·看过、剧集·看过的水位都为 "2026-10-18 08:25:08"，两个类别都勾选
  And 豆瓣影视看过第一页依次是 3 条晚于水位的新标记、1 条恰为水位的标记、16 条更早的标记
When 我点"同步新标记"
Then 只处理前 4 条（3 条新增，水位那条按 BH-08 覆盖）
  And 影视·看过不再请求第二页
  And 电影、剧集的看过水位都前移到第一条新标记的时间
Given 电影·看过水位为 "2026-10-18 08:25:08"，剧集·看过水位为更早的 "2026-10-01 12:00:00"，两个类别都勾选
When 我点"同步新标记"
Then 影视·看过翻到早于 "2026-10-01 12:00:00" 的标记才停（以较早的水位为准，不漏剧集的标记）
```

## BH-23: 同步新标记：与水位同一秒的标记仍处理

**SC-ID**: SC-IMPORT-23

```gherkin
Given 水位为 "2026-10-18 08:25:08"，豆瓣有两条标记时间都是 "2026-10-18 08:25:08"，其中一条上次同步时还没出现
When 我点"同步新标记"
Then 两条都被处理（已有的覆盖、没有的新增），不会漏掉同一秒的标记
```

## BH-24: 水位只在一步完整同步后前移

**SC-ID**: SC-IMPORT-24

```gherkin
Given 六个类别的看过 / 读过 / 玩过、在看 / 在读 / 在玩水位都为 T0，六个都勾选
When 同步新标记时影视·看过翻完（到达水位），随后在书·读过第 2 页点了"停止"
Then 电影、剧集的看过水位前移到本次影视·看过第一条标记的时间
  And 书、漫画的读过水位保持不变，同步时间不更新
When 全量导入中途某一页返回 FETCH_FAILED
Then 出错这一步涉及的类别水位不变；之前已完整翻完的步骤，其勾选类别的水位已前移
```

## BH-25: 勾选的类别有一个没有水位时这一步按全量处理

**SC-ID**: SC-IMPORT-25

```gherkin
Given 电影·看过、书·读过、漫画·读过有水位，剧集·看过没有水位（上次只导入了电影），六个类别都勾选
When 我点"同步新标记"
Then 影视·看过从第一页翻到最后一页（电影条目重复覆盖无害）
  And 书·读过只同步水位之后的标记
  And 翻完后剧集·看过也有了水位，电影·看过的水位前移
```

## BH-26: 在看改看过后同步新标记更新为已完成

## BH-28: 只勾选部分类别：未勾选类别的标记不写入、已有条目不改动

**SC-ID**: SC-IMPORT-28
