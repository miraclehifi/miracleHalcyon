# 读者浏览书影音

**US ID**: US-03
**所属分组**: media-shelf
**状态**: draft

---

## 1. User Story

**作为** 读者
**我想要** 在 `/media` 按分类浏览作者读过、看过、玩过以及正在进行的条目
**以便于** 了解作者的阅读和娱乐口味

---

## 2. 验收标准

1. Given 我在任意读者页
   When 我点顶栏"书影音"
   Then 进入 `/media`（不再是 404），默认显示"书"分类

2. Given 我在 `/media`
   When 我点分类标签（书 / 漫画 / 电影 / 剧集 / 游戏 / 桌游）
   Then 显示该分类的条目，当前标签高亮；页头显示该分类数量与进行中数量（如"128 本 · 在读 2"）

3. Given 某分类下有进行中和已完成的条目
   When 我查看该分类
   Then 进行中的条目置顶并带"在读 / 在看 / 在玩"标记，其余按标记日期倒序

4. Given 一个条目
   When 我查看它
   Then 所有分类都以满宽海报墙显示（与电影同版式，没有居中窄栏）：正面是封面（书、漫画、电影、剧集 2:3，桌游 1:1，游戏按原比例），悬停浮出名称（游戏见 AC14），名称、我的评分（5 颗表情星：点亮前 N 颗，其余灰色占位；无评分不显示）、短评与"读过 / 看过 / 玩过 · 日期"在海报背面，不显示作者 / 导演 / 开发商（见 AC12）

5. Given 条目有豆瓣链接
   When 我点它
   Then 在新标签页打开豆瓣条目页；条目上显示"豆瓣 ↗"

6. Given 条目没有豆瓣链接
   When 我查看它
   Then 它不可点击，不显示"豆瓣 ↗"

7. Given 条目被作者隐藏
   When 我浏览 `/media`
   Then 看不到它，数量统计也不计入

8. Given 条目封面缺失或加载失败
   When 我查看它
   Then 显示占位底色与"图片不可用"图标，布局不错位

9. Given 某分类下没有条目
   When 我切到该分类
   Then 显示空状态提示，而不是空白

10. Given 我用手机（390px）访问
    When 我浏览 `/media`
    Then 布局按手机稿显示，海报墙 2 列，分类标签放不下时换行，无整页横向滚动

11. Given 作者新增、编辑、隐藏或删除了条目
    When 重建完成后我访问 `/media`
    Then 看到更新后的内容（P95 ≤ 5 分钟）

12. Given 我在任一分类
    When 我把指针移到一张海报上，再点它
    Then 悬停时海报只倾斜、反光，不浮出名称（游戏显示平台与年份）；点击后海报原地翻到背面，显示名称、评分、短评、标记日期（精确到日；进行中为"在读 / 在看 / 在玩"）与"豆瓣 ↗"，不显示作者 / 导演 / 开发商；再点或按 Esc 翻回；同一时间只翻开一张

13. Given 我在任一分类
    When 我打开"按时间"
    Then 可以选择按标记时间（看过 / 玩过）或发行年份（上映 / 首播 / 发售年份）分段：标记时间按"在看 / 本月 / 上个月 / 本年 / 去年 / 更早年份"（游戏为"在玩"，以我访问当天为准，空段不显示），发行年份每年一段倒序、没有年份的归"未知年份"；分段标题滚动时吸顶；关闭后恢复不分段；下次访问记得我的选择

14. Given 我在游戏分类
    When 我浏览、把指针移到一张封面上、再点它
    Then 版式与电影海报墙相同，但每张封面保持 IGDB 大图的原始比例、完整显示不裁切；悬停时不显示游戏名，左上角显示该条目的平台徽标（PS5 / PS4 / Switch / Switch 2 / Steam）、右下角显示发售年份（只有数字）；点击翻到背面，显示游戏名、评分、短评、玩过日期（精确到日；进行中为"在玩"）与"豆瓣 ↗"，不显示开发商与平台

---

## 3. 约束与假设

**约束**:
- 页面构建时预渲染；分类为路径路由：`/media` = 书，其余 `/media/:type`（design-ui 定）
- 页面不请求任何豆瓣域名资源；封面引用站内 R2，**游戏封面例外：直接引用 images.igdb.com 大图**（[ADR-013](../../../../../../engineering/features/F-005-书影音/architecture/adr/ADR-013-game-cover-igdb-link.md)）
- 海报墙形态与分类差异见 [reader-media.md](../../../../../../ui/pages/reader-media.md)

**假设**:
- 单个分类条目在数百条量级，首版不分页
