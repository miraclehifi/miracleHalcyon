## BH-01: 从顶栏进入 /media，默认显示书

**SC-ID**: SC-SHELF-01

```gherkin
Given 我在首页
When 我点顶栏"书影音"
Then 进入 /media，返回 200（不是 404）
  And "书"标签高亮，显示书分类的条目
```

## BH-02: 切换分类，当前标签高亮

**SC-ID**: SC-SHELF-02

```gherkin
Given 我在 /media
When 我点"电影"标签
Then 显示电影分类的条目，"电影"标签高亮，"书"标签不再高亮
  And 地址变为 /media/movie
```

## BH-03: 页头显示数量与进行中数量

**SC-ID**: SC-SHELF-03

```gherkin
Given 书分类有 10 条显示中的条目，其中 2 条在读
When 我查看书分类
Then 页头显示"10 本 · 在读 2"
Given 电影分类有 5 条，没有在看的
When 我查看电影分类
Then 页头显示"5 部"，不显示"在看 0"
```

量词按分类：书 / 漫画"本"，电影 / 剧集"部"，游戏 / 桌游"款"。

## BH-04: 进行中置顶带标记，其余按标记日期倒序

**SC-ID**: SC-SHELF-04

```gherkin
Given 剧集分类有：A 看过 2026-03-01、B 在看 2026-01-10、C 看过 2026-09-15
When 我查看剧集分类
Then 顺序为 B、C、A
  And B 带"在看"标记
```

## BH-05: 书、漫画以海报墙显示，背面看短评与状态

**SC-ID**: SC-SHELF-05

```gherkin
Given 书条目"原则"：作者"瑞·达利欧"、评分 4、短评"值得反复读"、读过 2026-10-01、有豆瓣链接
When 我查看书分类
Then 页面主体满宽、左对齐（与电影页相同），"原则"以 2:3 海报显示封面
When 我把指针移到"原则"上
Then 底部浮出"原则"
When 我点它
Then 翻到背面：名称、4 颗星、短评"值得反复读"、"读过 · 2026-10-01"和"豆瓣 ↗"，不显示"瑞·达利欧"
Given 书条目"三体"在读
Then 背面底部为"在读"标记而不是日期
```

书、漫画原为 `MediaCard` 两列网格，2026-10-23 改为海报墙（[media-wall-all-types](../../../../../../backlog/media-wall-all-types.md)）。


## BH-06: 桌游以 1:1 海报墙显示

**SC-ID**: SC-SHELF-06

## BH-07: 无评分时背面不显示星级

When 我分别翻开 A、B
Then A 背面显示 5 颗星，前 N 颗为点亮的实心星，其余为灰色占位
  And B 背面不显示星级，短评上移，海报尺寸与 A 相同

## BH-16: 页面不请求豆瓣域名资源

## BH-17: 页面为静态预渲染，只有分类导航与海报墙加载 React

**SC-ID**: SC-SHELF-17

```gherkin
Given 构建完成
When 检查 /media 的构建产物
Then 页面是预渲染的静态 HTML，包含全部显示中的条目
  And 只有分类导航岛（MediaTypeTabs）与每个分类页的海报墙岛（MediaPosterWall）引用 React 运行时脚本
```

分类切换仍是链接（无 JS 可用）；2026-10-22 起分类导航改用 GooeyNav 动效、电影与剧集改为可翻面的海报墙，为此加载 React（[gooey-media-tabs](../../../../../../backlog/gooey-media-tabs.md)、[media-poster-wall](../../../../../../backlog/media-poster-wall.md)，原为"不引用 React 运行时脚本"）。海报墙的条目在静态 HTML 中完整输出。

## BH-19: 海报墙悬停不显示名称、点击翻面看详情

**SC-ID**: SC-SHELF-19

```gherkin
Given 电影分类有"肖申克的救赎"（导演"弗兰克·德拉邦特"、评分 5、看过 2026-08-20、有豆瓣链接）和"无名片"
When 我把指针移到"肖申克的救赎"的海报上
Then 海报轻微倾斜并有反光，不浮出片名，也不显示导演
When 我点"肖申克的救赎"的海报
Then 海报原地翻到背面，显示片名、5 颗星、"看过 · 2026-08-20"和"豆瓣 ↗"，不显示导演
When 我再点"无名片"的海报
Then "无名片"翻开，"肖申克的救赎"自动翻回正面
When 我按 Esc
Then 翻开的海报翻回正面
```

海报正面不显示"在看"徽标；正面时"豆瓣 ↗"不可点、不可聚焦；无 JS 时海报不能翻面，"豆瓣 ↗"固定显示（[media-poster-wall](../../../../../../backlog/media-poster-wall.md)）。

## BH-20: 海报墙按时间分段开关

**SC-ID**: SC-SHELF-20

```gherkin
Given 今天是 2026-09-15，电影分类有"肖申克的救赎"（看过 2026-08-20）和"无名片"（看过 2026-07-01），我从未切换过"按时间"
When 我打开电影分类
Then 海报不分段，"按时间"按钮为未按下
When 我点"按时间"
Then 出现"上个月"段（含"肖申克的救赎"，标题 meta "8 月 · 1 部"）和"本年"段（含"无名片"，meta "2026 · 1 部"），不出现空段
When 我刷新页面
Then 仍按时间分段
When 我再点"按时间"
Then 恢复不分段
```

分段在浏览器按当天本地日期计算：1 月时上一年 12 月归"上个月"；晚于今天的日期归"本月"；进行中的条目归"在看"（游戏为"在玩"，量词"款"）（规则见 [reader-media.md](../../../../../../ui/pages/reader-media.md)"按时间分段"）。

## BH-21: 游戏海报墙：封面保持原比例、悬停显示平台、背面看详情

**SC-ID**: SC-SHELF-21

```gherkin
Given 游戏分类有"黑神话：悟空"（平台 PS5、开发商 Game Science、评分 4、玩过 2025-08-20、有豆瓣链接、IGDB 封面 810×1080）
  And "塞尔达传说：王国之泪"（平台 Switch、IGDB 封面 811×1080）和"博德之门 3"（平台 Steam、IGDB 封面 600×900）
When 我打开游戏分类
Then 海报墙与电影同版式（满宽、等宽列、按时间开关）
  And 每张封面的显示宽高比与它的 IGDB 大图一致（810:1080、811:1080、600:900），画面完整、不裁切
  And 封面图片地址为 images.igdb.com 的 t_1080p 大图
When 我把指针移到"黑神话：悟空"上（发售年份 2024）
Then 左上角出现"PS5"平台徽标，右下角出现"2024"
  And 不出现游戏名浮层
When 我把指针移到"博德之门 3"上
Then 左上角出现"Steam"平台徽标
When 我点"黑神话：悟空"
Then 翻到背面，显示"黑神话：悟空"、4 颗星、"玩过 · 2025-08-20"和"豆瓣 ↗"，不显示"Game Science"，也不显示平台
```

触屏设备没有悬停，平台与年份都不显示（背面也不显示平台，作者取舍）；没有年份的游戏悬停时只显示平台。翻面、只翻一张、Esc 翻回、无 JS 兜底同 BH-19。

## BH-22: 游戏无封面或封面加载失败时显示占位

**SC-ID**: SC-SHELF-22

```gherkin
Given 游戏条目"某款老游戏"没有封面，条目"断链游戏"的 IGDB 封面（810×1080）加载失败
When 我打开游戏分类
Then "某款老游戏"按 3:4 显示占位，"断链游戏"按记录的 810:1080 显示占位，砖块尺寸不跳动
  And 占位为底色、"图片不可用"图标与游戏名；悬停仍显示平台徽标，仍可翻面
```

## BH-23: 按时间时切换为按发行年份分段

**SC-ID**: SC-SHELF-23

```gherkin
Given 游戏分类有：影之刃零（2026）、侠盗猎车手 6（2026）、黑神话：悟空（2024）、塞尔达传说：王国之泪（2023，在玩）、生化危机 4（2023）、某款老游戏（无年份）
When 我打开"按时间"
Then 按钮右侧出现"玩过时间 | 发售年份"，默认"玩过时间"，分段同 BH-20
When 我选"发售年份"
Then 分段依次为"2026"（meta "2 款"）、"2024"（"1 款"）、"2023"（"2 款"，王国之泪在前）、"未知年份"（"1 款"）
  And 没有"在玩"段
When 我刷新页面
Then 仍按发售年份分段
When 我关闭"按时间"
Then 恢复不分段，"玩过时间 | 发售年份"消失
```

其他分类同理（书 / 漫画"读过时间 | 出版年份"，电影"看过时间 | 上映年份"，剧集"看过时间 | 首播年份"，桌游"玩过时间 | 发行年份"），选择所有分类共用（[media-time-basis](../../../../../../backlog/media-time-basis.md)）。
