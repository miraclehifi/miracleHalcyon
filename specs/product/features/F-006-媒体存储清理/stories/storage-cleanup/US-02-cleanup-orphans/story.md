# 一键清理未引用媒体

**US ID**: US-02
**所属分组**: storage-cleanup
**状态**: draft

---

## 1. User Story

**作为** 作者
**我想要** 一键删掉所有未引用的图片和实况视频
**以便于** 释放存储，又不用担心删到文章正在用的文件

---

## 2. 验收标准

1. Given 未引用图片与未引用实况视频的数量都是 0
   When 我查看存储页
   Then "一键清理未引用资源"按钮禁用，显示"存储状态良好，无未引用文件"

2. Given 有未引用资源
   When 我点"一键清理未引用资源"
   Then 弹出确认框，写明将清理的图片张数、视频个数、可释放体积，以及"清理后无法恢复"；我可以取消，取消后不做任何改动

3. Given 我在确认框中确认
   When 清理完成
   Then 未引用图片的文件（连同其实况视频）与记录被删除；未引用实况视频的文件被删除，所属图片保留并不再带视频；统计刷新为 0，提示"已清理 X 项，释放 Y MB"

4. Given 我打开存储页之后，又在写文章页把其中一张"未引用"图片插回了某篇文章并已保存
   When 我回到存储页确认清理
   Then 这张图片不会被删除（清理时按当时的文章内容重新判定）

5. Given 清理过程中途出错
   When 清理失败
   Then 提示"清理未完成，请重试"；已删除的不恢复，未删除的保持原样；再次清理可以继续完成

6. Given 某张图片的实况视频已被清理
   When 我在文章里重新给它加上 `live` 标记
   Then 预览和读者页尝试播放实况失败后隐藏 `LIVE` 标记、只显示静态图，不报错（沿用 US-11 AC8 的降级）

---

## 3. 约束与假设

**约束**:
- 清理与检测使用同一判定规则（见 [US-01](../US-01-detect-orphans/story.md)，含 24 小时保护期）
- 只支持全量清理，不支持按张选择
- 清理不可撤销

**假设**:
- 单作者使用，不考虑两个人同时清理
