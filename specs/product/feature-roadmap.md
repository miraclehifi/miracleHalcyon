# miracleHalcyon Feature 路线图

**最后更新**: 2026-10-12
**状态**: approved

---

## Feature 划分原则

1. **独立可交付**: 每个 Feature 可以独立上线，有独立的业务价值
2. **边界清晰**: Feature 之间通过 Domain 接口交互，不共享内部实现
3. **职责单一**: 一个 Feature 聚焦一个业务能力

## Feature 列表

| 优先级 | Feature ID | 名称 | 说明 | 依赖 | 状态 |
|--------|------------|------|------|------|------|
| P1 | F-001 | 文章写作 | 管理员登录后在线写作、预览、上传图片、自动保存草稿、发布文章 | — | planning |
| P1 | F-002 | 博客首页与阅读 | 首页（自我介绍）、文章列表页 `/posts`、文章详情页、按标签浏览、读者端顶栏 / 页脚 | F-001 | planning |
| 后续 | F-003 | 作品集 | 项目展示与项目详情 | F-002 | idea |
| 后续 | F-004 | 互动与发现 | 评论（Giscus）、站内搜索、RSS、SEO | F-002 | idea |
| 后续 | F-005 | 书影音 | `/media` 记录看过的书、电影、剧、动画、游戏 | F-002 | idea |

**顺序理由**: F-001 先行，先有写作能力才能产出真实文章，F-002 直接使用真实数据，无需构造假数据。

## Feature 边界说明

| Feature | 负责 | 不负责 |
|---------|------|--------|
| F-001 文章写作 | 管理员账号密码登录/登出；写文章页（文章信息表单、Markdown 实时预览、图片上传、自动保存草稿）；发布、更新文章；定义文章数据模型 | 读者端页面展示；评论；多作者 |
| F-002 博客首页与阅读 | 首页（自我介绍）；文章列表页 `/posts`；文章详情页渲染；标签筛选页；读者端顶栏（含摄影外链）与页脚 | 文章的创建与修改；搜索；评论；书影音 |
| F-003 作品集 | 项目列表与项目详情 | 文章相关功能 |
| F-004 互动与发现 | 评论、站内搜索、RSS、SEO 元数据 | 文章写作 |
| F-005 书影音 | 书影音条目的展示（分类切换）与数据来源 | 文章相关功能 |

## 依赖关系

```
F-001 文章写作 ──(post Domain: 已发布文章)──▶ F-002 博客首页与阅读
                                               ├──▶ F-003 作品集
                                               ├──▶ F-004 互动与发现
                                               └──▶ F-005 书影音
```

- **共享 Domain `post`**：由 F-001 定义并负责写入；F-002 仅读取已发布文章
