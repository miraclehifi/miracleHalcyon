# miracleHalcyon 全局非功能需求

**最后更新**: 2026-10-10
**状态**: approved

> 本文档定义产品级别的非功能需求，适用于所有 Feature。
> Feature 级别的特殊 NFR 在各 Feature 的 nfr.md 中定义。

---

## 1. 性能需求

| 指标 | 要求 | 衡量方式 | 优先级 |
|------|------|----------|--------|
| 读者页面 LCP | < 2.5s | Lighthouse（移动端模拟） | P1 |
| 读者页面 Performance 分 | ≥ 90 | Lighthouse | P1 |
| 读者页面 JS 体积 | 无交互页面不加载 React 运行时 | 构建产物检查 | P1 |
| 写作接口响应 | P95 < 500ms | Cloudflare 日志 | P2 |

读者页面（首页、文章页）须利用预渲染或边缘缓存；发布/更新文章后缓存须失效。

---

## 2. 安全需求

### 2.1 认证与授权

| 类别 | 要求 |
|------|------|
| 认证方式 | 单管理员账号密码登录，不开放注册 |
| 会话 | 服务端会话 + Cookie（`HttpOnly`、`Secure`、`SameSite=Lax`） |
| 会话有效期 | 7 天，登出即失效 |
| 授权 | 所有写操作接口与 `/admin` 页面必须校验会话，未登录返回 401 / 跳转登录 |
| 登录限流 | 同一 IP 连续失败 5 次后锁定 15 分钟 |

### 2.2 数据安全

| 类别 | 要求 |
|------|------|
| 传输加密 | 全站 HTTPS |
| 密码存储 | 不可逆哈希（PBKDF2/scrypt 等 Workers 可用算法），禁止明文 |
| 机密配置 | 管理员凭据、密钥通过 Cloudflare Secrets 注入，不进 git |
| 写接口防护 | 校验 Origin 防 CSRF |
| 内容渲染 | Markdown 渲染输出须防 XSS |
| 图片上传 | 存储格式仅允许 png/jpg/webp/gif（禁止 svg，防 XSS），单张 ≤ 5MB；HEIC/HEIF 在浏览器端转为 JPEG 后上传；服务端按文件头校验类型 |
| 实况视频 | 仅作为实况照片与静态图配对上传；存储为 mp4，单个 ≤ 10MB；MOV 在浏览器端转换后上传 |

---

## 3. 数据与灾难恢复

| 指标 | 要求 |
|------|------|
| 备份 | D1 定期导出（至少每周一次），可手动触发 |
| 误操作恢复 | 依赖 D1 Time Travel 可恢复至 30 天内任意时间点 |
| 草稿 | 编辑中自动保存，关闭页面后不丢失内容 |

---

## 4. 兼容性需求

| 方面 | 要求 |
|------|------|
| 浏览器 | Chrome / Edge / Firefox / Safari 最新两个版本 |
| 移动端 | 读者页面适配 ≥ 360px 宽度；写作页以桌面为主，移动端可用 |
| 主题 | 支持亮色/暗色模式，默认跟随系统 |

---

## 5. 可维护性需求

| 方面 | 要求 |
|------|------|
| 日志 | 使用 Cloudflare 内置日志；不记录密码、会话 Token |
| 监控 | Cloudflare Web Analytics 统计访问 |
