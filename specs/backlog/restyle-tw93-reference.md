## 描述

作者指定以 [潮流周刊 #284](https://weekly.tw93.fun/posts/284) 为全站风格参考，替换原"温暖纸感"令牌。参考站与本项目同为 Astro + Pagefind + Giscus 技术栈，风格可直接落地。

参考站风格要点（从其 CSS 提取）：

| 维度 | 参考站做法 |
|------|-----------|
| 字体 | 全站楷体（仓耳今楷 02），代码 SF Mono；中文排版用 heti（赫蹏） |
| 配色 | 白底 `#fff` / 正文 `#262626` / 强调暖棕 `#a67c52`；暗色 `#21262b` / `#e7e9ea` / `#e8a15a` |
| 字号 | 正文 16px · 行高 1.7；h1 32 / h2 24 / h3 20，标题字间距 0.8px |
| 版心 | 正文最宽 864px；三栏（左导航 320 / 正文 / 右目录 208），窄屏依次收起 |
| 细节 | 圆角 8px；过渡 0.2s ease；链接无下划线，hover 显示 1px 底边；无渐变、无卡片阴影 |
| 读者功能 | 阅读模式（隐藏两侧栏）、图片点击放大 |

## 目标与验收

**目标**: 全站视觉换成参考站风格，同时保留现有令牌的无障碍约束（WCAG AA）。

**验收条件**:
- [x] [design-tokens.md](../ui/design-tokens.md) 按参考站重写：颜色、字体、字号、圆角、过渡、链接样式
- [x] 所有文字色在其可能出现的底色上 ≥ 4.5:1，`input-border` / `focus` ≥ 3:1（亮暗两套）
- [x] [admin.pen](../ui/admin.pen) 变量与组件按新令牌更新，页面视觉与令牌一致
- [x] 引用旧令牌名 / 旧风格描述的 specs 同步（`specs/_index.md`、`components.md`）

## 影响分析

- **影响范围**: `specs/ui/design-tokens.md`、`specs/ui/admin.pen`、`specs/_index.md`、`specs/ui/components.md`
- **依赖项**: 无
- **被依赖**: F-001 `ui_design` 审阅；F-002 读者端页面设计（三栏布局、阅读模式、版心 864px 作为其输入）
- **决策**:
  - 强调色：参考站 `#a67c52` 在白底仅 3.73:1，不满足文字/按钮 AA，改用同色相加深的 `#8B6238`（5.38:1）
  - 字体：参考站的仓耳今楷授权条款未确认，改用开源可商用（OFL）的**霞鹜文楷**，同为楷体气质；作者可后续换回
  - 全站一套正文字体（楷体），取消原衬线/无衬线之分：`font-serif` / `font-sans` 合并为 `font-body`
  - 三栏布局、阅读模式属于读者端页面结构，不写入令牌，留给 F-002 design-ui
