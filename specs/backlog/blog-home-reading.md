## 描述

需要一个首页（自我介绍）、文章列表页（含标签入口）以及文章详情页。整站结构参考 [pseudoyu.com](https://www.pseudoyu.com/)，网站地图见 [site-map.md](../ui/site-map.md)（取舍见 [sitemap-pseudoyu-reference.md](sitemap-pseudoyu-reference.md)）。

## 目标与验收

**目标**: 读者可在首页了解作者，在 `/posts` 浏览文章并进入详情阅读，可按标签筛选。

**验收条件**:
- [ ] 首页为自我介绍页：头像、几段简介、社交链接、邮箱；不列文章
- [ ] `/posts` 展示文章列表（时间倒序、分页）、标签入口
- [ ] 读者端顶栏：站点名回首页、文章、书影音、摄影外链、GitHub、RSS、主题切换；子页底部 `> cd ..` 返回上一级
- [ ] 文章详情页渲染 Markdown（代码高亮、暗色模式）
- [ ] 文章详情页阅读细节：纸张正文区、段首缩进、首字下沉、引用署名；三栏（同标签文章 / 正文 / 阅读进度与目录）；文末上一篇 / 下一篇
- [ ] 按标签浏览文章
- [ ] 草稿不对读者可见
