## 描述

[design-component-library](design-component-library.md) 完成后，[admin.pen](../ui/admin.pen) 组件区排布凌乱：各区组件单行横排、宽度参差（"反馈"一行拉到 3000px），变体之间无标注；页面区移动端画板顺序错乱（03m/01m/02m）且远离对应桌面页。只调整画布版式，不改组件和页面内容。

## 目标与验收

**目标**: 组件区像一张组件清单页，按区 → 组件 → 变体逐级可读；页面区桌面 / 移动 / 状态分行，移动页与桌面页对应。

**验收条件**:
- [x] 组件区固定宽度，各区标题样式一致，区与区之间有分隔线
- [x] 每个组件一组：组件名标签 + 各变体，变体下方标注 variant 名
- [x] 过宽的区按组件拆成多行，无单行超宽
- [x] 组件本身（尺寸、样式、ID）不变，页面区实例不受影响
- [x] 页面区分"桌面 / 移动 / 状态与弹层"三行，每行带标题；移动页按 01m→02m→03m 排在对应桌面页正下方
- [x] 画板之间无重叠
- [x] 移动页统一 390 × 844：02m 由内容撑高（956）改为固定 844，列表删去与第 3 行重复的两行"已发布"示例，分页仍在首屏内
