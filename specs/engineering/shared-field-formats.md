# 字段格式规范（项目级 SSOT）

**最后更新**: 2026-10-22

> API 请求/响应与验收用例中的类型字段一律按本表。新增类型先补本表再使用。
> 与插件标准表的差异及理由见"偏离说明"。

| 字段类型 | 格式 | 示例 | 说明 |
|---------|------|------|------|
| 时间戳 | ISO 8601 UTC，毫秒精度 | `2026-10-13T06:30:00.000Z` | 前端按浏览器时区显示（"已保存 · 14:30"、相对时间） |
| 日期 | `yyyy-MM-dd` | `2026-10-13` | 文章"发布日期"`publishedAt`，不带时区，按作者填写原样存储 |
| 枚举 | 小写，多词用下划线 | `draft`、`published`、`grid`、`accordion` | 与 components.md 的 prop 取值一致，前端不做映射 |
| 错误码 | 大写下划线 | `SLUG_TAKEN`、`RATE_LIMITED` | 只出现在错误响应 `error.code` |
| 文章 ID | 十进制整数的字符串 | `"42"` | D1 `INTEGER PRIMARY KEY`；JSON 中用字符串，前端不做数值运算 |
| slug | `^[a-z0-9]+(?:-[a-z0-9]+)*$`，1–80 字符 | `hello-astro` | 全站唯一（ADR-002） |
| 标签 | 去首尾空白，1–32 字符，按原大小写存储，比较时不区分大小写 | `Astro` | 一篇文章最多 10 个 |
| 颜色 | 6 位小写 hex，不带 `#` | `8a7b6c` | 图片主色（ADR-005） |
| 图片 URL | 站内相对路径 | `/img/2026/10/k3j9x2m4q1_4032x3024_8a7b6c.jpg` | 见 media 数据模型 |
| 文件体积 | JSON 中为整数字节；显示时 1 MB = 1,048,576 B：≥ 1 MB 保留 1 位小数（`5.7 MB`），< 1 MB 显示为向上取整的 KB（`320 KB`），0 显示 `0 MB` | `26552460` → `25.3 MB` | F-006 存储统计；与上传上限"50MB = 50 MiB"同口径 |
| 书影音分类 | 枚举 | `book`、`comic`、`movie`、`series`、`game`、`boardgame` | F-005；显示名：书 / 漫画 / 电影 / 剧集 / 游戏 / 桌游 |
| 书影音状态 | 枚举 | `completed`、`in_progress` | F-005；显示动词按分类：读过 / 在读（书、漫画）、看过 / 在看（电影、剧集）、玩过 / 在玩（游戏、桌游） |
| 书影音条目 ID | 十进制整数的字符串 | `"7"` | 同文章 ID |
| 游戏平台 | 枚举 | `ps5`、`ps4`、`switch`、`switch2`、`steam` | F-005（ADR-013）；显示名 PS5 / PS4 / Switch / Switch 2 / Steam；只用于游戏 |
| IGDB 封面地址 | URL | `https://images.igdb.com/igdb/image/upload/t_1080p/co8h3y.jpg` | F-005（ADR-013）；只存规范形式（`t_1080p`、`.jpg`） |
| 豆瓣条目 ID | 纯数字字符串 | `"1292052"` | 取自 `/subject/{id}/`；无豆瓣链接时为 `null` |
| 评分 | 整数 1–5 或 `null` | `4` | F-005 我的评分，显示为星级 |
| 年份 | 4 位整数或 `null` | `2018` | F-005 条目年份 |
| 标记年月 | 显示用 `yyyy-MM` | `2026-10` | 由标记日期（"日期"格式）截取 |

## 偏离说明（相对插件标准表）

| 项 | 插件标准 | 本项目 | 理由 |
|----|---------|--------|------|
| 时间戳 | `yyyy-MM-dd HH:mm:ss` | ISO 8601 UTC | Workers 运行在 UTC，作者在浏览器本地时区查看，无时区的格式会产生歧义；验收用例已按 ISO 8601 断言 |
| 枚举 | 大写下划线 | 小写 | 与组件 prop（`StatusBadge status="draft"`）和验收用例一致，避免两套写法 |
