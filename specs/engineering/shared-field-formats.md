# 字段格式规范（项目级 SSOT）

**最后更新**: 2026-10-13

> API 请求/响应与验收用例中的类型字段一律按本表。新增类型先补本表再使用。
> 与插件标准表的差异及理由见"偏离说明"。

| 字段类型 | 格式 | 示例 | 说明 |
|---------|------|------|------|
| 时间戳 | ISO 8601 UTC，毫秒精度 | `2026-10-13T06:30:00.000Z` | 前端按浏览器时区显示（"已保存 · 14:30"、相对时间） |
| 日期 | `yyyy-MM-dd` | `2026-10-13` | 文章"发布日期"`publishedAt`，不带时区，按作者填写原样存储 |
| 枚举 | 小写，多词用下划线 | `draft`、`published`、`grid`、`accordion` | 与 components.md 的 prop 取值一致，前端不做映射 |
| 错误码 | 大写下划线 | `SLUG_TAKEN`、`RATE_LIMITED` | 只出现在错误响应 `error.code` |
| 文章 ID | 十进制整数的字符串 | `"42"` | D1 `INTEGER PRIMARY KEY`；JSON 中用字符串，前端不做数值运算 |
| slug | `^[a-z0-9]+(?:-[a-z0-9]+)*$`，1–80 字符 | `hello-astro` | 全站唯一（ADR-002） |
| 标签 | 去首尾空白，1–32 字符，按原大小写存储，比较时不区分大小写 | `Astro` | 一篇文章最多 10 个 |
| 颜色 | 6 位小写 hex，不带 `#` | `8a7b6c` | 图片主色（ADR-005） |
| 图片 URL | 站内相对路径 | `/img/2026/10/k3j9x2m4q1_4032x3024_8a7b6c.jpg` | 见 media 数据模型 |

## 偏离说明（相对插件标准表）

| 项 | 插件标准 | 本项目 | 理由 |
|----|---------|--------|------|
| 时间戳 | `yyyy-MM-dd HH:mm:ss` | ISO 8601 UTC | Workers 运行在 UTC，作者在浏览器本地时区查看，无时区的格式会产生歧义；验收用例已按 ISO 8601 断言 |
| 枚举 | 大写下划线 | 小写 | 与组件 prop（`StatusBadge status="draft"`）和验收用例一致，避免两套写法 |
