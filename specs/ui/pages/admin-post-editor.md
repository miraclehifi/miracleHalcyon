# 写文章页（Admin Post Editor）

**路由**: `/admin/posts/new`（新建）、`/admin/posts/:id`（编辑）
**状态**: draft
**关联**: F-001 · US-03、US-04、US-05、US-06、US-08、US-09、US-10、US-11、US-12

## 页面用途

写 Markdown 正文、即时看到读者端效果，并决定何时发布。正文区是页面的主体，其余信息收进可开合的设置抽屉。

## 入口与出口

| 从哪来 | 去哪里 |
|--------|--------|
| 列表"新建文章" / "写第一篇" | "← 文章" → `/admin` |
| 列表点击文章 | 删除并确认 → `/admin` |
| 直接访问（含登录后 `next` 回跳） | 登出 → `/admin/login` |

新建页首次自动保存成功后，地址换成 `/admin/posts/:id`（不刷新）。

### 编辑区（左）

- **标题**：无边框大号输入框，占位"无标题"；回车把光标移到正文
- **工具栏**：二级标题、加粗、斜体、链接、行内代码、列表、任务列表、引用 | 插入图片（选文件）、实况照片（开关）。全部为图标按钮（`IconButton/Ghost`），"插入图片"与格式按钮之间用竖线分隔。按钮在光标处插入/包裹 Markdown 语法；名称、快捷键、提示见下方"工具栏与悬停提示"（US-10）
- **源码区**：等宽字体，支持粘贴 / 拖入图片（含安卓动态照片，自动识别为实况照片；拖入时整个编辑区显示虚线描边 + "松开以上传图片"）
- **粘贴 Afilmory 照片**（US-13）：粘贴的文本整体是登记站点的单张 / 多张分享代码或照片页链接时，不插入原文，按图片上传同样插入 `![处理中…]()` 占位（多张每张一行），预览显示 `UploadCard`（"正在获取照片信息…"，没有缩略图，进度按时间趋近）；取到信息后替换为外链引用。失败卡片原因为接口文案（"Afilmory 暂时无法访问" / "Afilmory 中没有这张照片"），重试重新获取、移除删行。按标签分享的代码不插入，弹错误提示；其他文本照常粘贴。实况开关开启且为动态照片时引用带 `live`。已实现（Sprint 8）
- **上传占位**（US-05、US-11）：源码中先插入 `![处理中…]()`（浏览器端压缩、计算主色；实况开关开启且识别为动态照片时还要切视频、转码），开始上传后变为 `![上传中…]()`，完成后替换为引用；失败时变为 `![上传失败]()`（保留在原位，等作者在预览卡片上重试或移除）。进度与操作都在预览区的 `UploadCard` 上，源码区只有占位文本。"插入图片"的文件选择框接受 png、jpg、webp、gif，可多选（不支持 HEIC 与单独的视频文件，2026-10-15）
- **底栏**：左"Markdown (GFM) · 支持粘贴/拖入图片 · 图片写法"（"图片写法"为文字按钮，见下方"图片写法说明"）；右字数（`tabular-nums`，不计空白的字符数，千分位）
- 已实现（Sprint 1）：`src/components/admin/editor/MarkdownEditor.tsx`——标题、源码区、底栏字数；底栏左侧在图片上传接入前只显示"Markdown (GFM)"

### 预览区（中）

- `surface` 底色，顶部小标签"预览"，其下以读者端 H1 样式显示文章标题；排版与读者端一致（衬线正文、Expressive Code 代码块）
- 并排模式下预览区比读者端窄，行宽不代表真实效果；要核对真实行宽切到"预览"模式（预览区内容最大宽度与读者端正文一致，约 680px）
- 正文停止输入后 300ms 内更新；与编辑区同步滚动（US-04-6）
- 渲染失败（US-04 BH-09）：保留上一次的预览内容，"预览"标签下方显示 `Alert/Error`"预览渲染失败，继续编辑会自动重试"；下一次渲染成功后提示消失（已实现，`MarkdownPreview.tsx`）
- 源码中的上传占位在预览中显示为上传进度卡片 `UploadCard`，规则见下方"上传进度卡片"（原占位块"图片上传中… 文件名"由它取代，2026-10-16）
- 图片按读者端组件显示：`ArticleImage`（含宽图、图注、实况照片 `LiveBadge`）、`ImageGallery`（网格 / 手风琴），写法见 ADR-005；预览中点击图片不打开灯箱
- 输入时已加载的图片保持原状，不重复播放加载动画（US-12 BH-13）
- 已实现（Sprint 1）：Web Worker 渲染、读者端 H1 标题、文章区排版、空正文占位；视图切换、窄屏 Tab 已实现（Sprint 2，`useEditorView`）；同步滚动、图片组件在后续任务

### 上传进度卡片（US-05、US-11）

组件 `UploadCard`（见 [components.md](../components.md)），一张图片一张卡片，按源码中占位的顺序出现在对应位置。

| 项 | 规则 |
|----|------|
| 尺寸 | 宽度与正文列一致；高度按缩略图比例，限制在 160–320px（缩略图未解码出来前 160px）；圆角 `radius`，`surface-sunken` 底 |
| 缩略图 | 文件进入队列即用 `URL.createObjectURL` 显示，`object-fit: cover`，不透明度 0.5、模糊 6px；完成、移除或页面卸载时回收 URL |
| 状态栏 | 卡片底部，`surface` 底 + 顶部 1px `line`：左侧图标 + 阶段文案（`text-caption`，`ink`），右侧文件名（等宽，`ink-faint`，过长中间省略）；下方 3px 进度条（`line` 轨道、`accent` 填充，`role="progressbar"`，`aria-valuenow` 0–100，`aria-label`"{文件名} 上传进度"） |
| 阶段 | 等待中（队列并发 2，排队时）："等待中…"，进度 0、无动画 → 压缩："正在压缩…"，0–15% 按时间平滑推进 → 处理实况视频（仅实况开关开启且识别为动态照片）："正在处理实况视频…"，15–40% 按时间平滑推进 → 上传："正在上传… N%"，真实字节进度，从上一阶段的终点走到 100%。进度只增不减 |
| 仅转为静态图 | 处理实况视频阶段，卡片右上角 12px 处显示 `Button/Ghost`"仅转为静态图"（图标 `image`）；点击后放弃本张视频、直接进入上传，按钮消失；其他阶段、其他卡片不显示 |
| 成功 | 卡片 200ms 淡出，同位置换成正式图片（`ArticleImage`，自带加载动画）；减弱动效时不淡出，直接替换 |
| 失败 `UploadCard/Error` | 1.5px `danger` 描边，缩略图不透明度降到 0.3；状态栏改为 `danger-soft` 底，图标 `circle-alert` + 原因（`danger`）：网络中断 →"网络中断"；超时 →"上传超时，请重试"；服务端错误 → 服务端返回的文案，没有时"上传失败，请重试"。卡片中部"重试"（`Button/Secondary`，`rotate-ccw`）和"移除"（`Button/Ghost`，`x`）。不再弹 Toast。重试从压缩重新开始；移除删掉源码中的占位（可撤销） |
| 已中断 `UploadCard/Interrupted` | 占位没有对应的上传任务（页面刷新后、撤销"移除"后）：高 120px，无缩略图与进度条，`line-strong` 描边，居中显示 `image-off` 图标 +"上传已中断"和"移除"（`Button/Ghost`）。处理中 / 上传中 / 上传失败三种占位都按此显示 |
| 无障碍 | 卡片 `role="group"`，`aria-label`"{文件名}"；阶段文案在 `aria-live="polite"` 区域，只在阶段切换和失败时播报，不逐个百分比播报 |
| 测试钩子 | `data-testid="upload-card"`，`data-state`：`waiting` / `compressing` / `processing-live` / `uploading` / `error` / `interrupted` |

- 已实现（Sprint 6）：`src/components/admin/editor/UploadCard.tsx`，数据来自 `use-image-uploads.ts` 的占位槽位（`UploadView`），`MarkdownPreview` 按占位序号挂载

读者端不渲染上传占位（任何状态都不输出内容，US-05 AC10）。

### 图片菜单（US-12）

预览中的单图和组图都有一个"图片选项"菜单，用来改写源码里的排版标记。组件 `ImageMenu`（见 [components.md](../components.md)）。

| 项 | 规则 |
|----|------|
| 触发按钮 | `OverlayButton`（`size` 32，图标 `ellipsis`，`aria-label`"图片选项" / "组图选项"），在图片或组图右上角内侧 8px；鼠标悬停在图片 / 组图上、或焦点进入时显示，平时隐藏（`opacity: 0`，仍可 Tab 聚焦）。组图内的单张图片不显示自己的按钮 |
| 打开 | 点击按钮，或聚焦后按 Enter / Space / ↓；菜单在按钮下方右对齐，空间不够时翻到上方 |
| 单图菜单 | `menuitemcheckbox`"宽图"（选中时右侧显示 ✓）；该图存有实况视频时下面再加 `menuitemcheckbox`"实况"（URL 片段含 `live` 时 ✓），取消 / 勾选会去掉 / 加回 `live`，保留其他标记。是否有视频在第一次打开菜单时检查（检查期间不显示该项），结果在本次页面会话内缓存；没有视频（含已被清理）不显示。Afilmory 照片（US-13）不发请求：片段带 `mp=` 即显示"实况"项 |
| 组图菜单 | `menuitemradio`"网格" / "手风琴"（当前形态显示 ✓）→ 分隔线 → `menuitem`"拆成单图"。张数不在 3–7 时"手风琴"设为 `aria-disabled`，悬停 / 聚焦时提示"手风琴需要 3–7 张图片" |
| 执行 | 改写源码（与格式工具栏同一套写入方式，可 ⌘Z / Ctrl+Z 撤销）→ 预览重新渲染 → 菜单保持打开并停在原项，可以继续调整；"拆成单图"后组图消失，菜单关闭 |
| 关闭 | Esc、点菜单外、滚动预览区，或源码变化导致该图片在预览中消失 / 位置失效时关闭；关闭后焦点回到触发按钮（按钮已被移除时回到预览区） |
| 键盘 | 打开后焦点在第一项；↑ / ↓ 循环；Home / End；Space / Enter 执行 |
| 手机 | 点按图片或组图直接展开菜单（按钮同时显示），菜单项高 44px；点菜单外关闭；长按留给实况照片播放，不打开菜单 |
| 定位 | 按渲染时记录的源码位置 + URL 双重核对，核对不上时不改写并关闭菜单（US-12 BH-11） |

### 图片写法说明（US-12）

底栏"图片写法"打开一个浮层（`Popover`，非模态，`role="dialog"`，`aria-label`"图片写法"），位于按钮上方、左对齐，宽 360px，最高 60vh，超出时内部滚动。

| 区块 | 内容 |
|------|------|
| 写法示例 | 5 行，每行左侧说明，右侧是等宽字体示例 + 复制按钮（`IconButton/Ghost` `copy`，提示"复制"，复制后图标变 ✓ 1.5 秒）：宽图 `![](url#wide)`；实况照片 `![](url#live)`（"拖入安卓动态照片会自动生成"）；图注 `![](url "图注")`；组图网格"连续几行只放图片，中间不空行"；手风琴"组图第一张加 `#accordion`，3–7 张" |

打开时焦点移到浮层标题；Esc 或点外部关闭，焦点回到"图片写法"按钮。手机：入口放在设置底部面板最下方（文字按钮"图片写法"），点开后在面板内展开同样的内容，不另开浮层。

### 设置抽屉（右，宽 340px）

| 字段 | 控件 | 规则 |
|------|------|------|
| Slug（文章网址） | 等宽输入框 | 提示行实时显示 `/posts/{slug}`；未手动改过时跟随标题自动生成，改过后不再跟随（US-03-2/3）；中文标题生成失败时留空，提示"请填写英文 slug"；只允许小写字母、数字、连字符 |

| 发布日期 | 日期选择 | 新建默认今天 |

抽屉默认：新建文章时**打开**（方便填信息），编辑已有文章时**关闭**。开合状态不跨文章记忆。

## 保存状态（US-06）

| 状态 | 图标 + 文案 | 颜色 |
|------|-----------|------|
| 已保存 | ☁✓ 已保存 · HH:mm | ink-faint |
| 未保存 | ● 未保存 | ink-muted |
| 保存中 | ⟳ 保存中… | ink-faint |
| 保存失败 | ☁✕ 保存失败，将自动重试 | danger |

- 任何字段（标题、设置抽屉、正文）变化都触发自动保存，停止输入 2 秒后保存
- 已发布文章的自动保存只产生"未发布修改"，徽标切到"已发布 · 有未发布修改"
- 有未保存修改时离开页面 → 浏览器原生离开确认
- 保存时间使用 `tabular-nums`，避免数字变化时抖动
- 已实现（Sprint 1）：自动保存、保存状态、离开确认、Ctrl / ⌘ + S 立即保存；本地暂存与恢复横幅、401 暂存后跳登录页已实现（Sprint 2）
