# 写文章页（Admin Post Editor）

**路由**: `/admin/posts/new`（新建）、`/admin/posts/:id`（编辑）
**状态**: draft
**关联**: F-001 · US-03、US-04、US-05、US-06、US-08、US-09、US-10、US-11、US-12

## 页面用途

写 Markdown 正文、即时看到读者端效果，并决定何时发布。正文区是页面的主体，其余信息收进可开合的设置抽屉。

## 入口与出口

| 从哪来 | 去哪里 |
|--------|--------|
| 列表"新建文章" / "写第一篇" | "← 文章" → `/admin` |
| 列表点击文章 | 删除并确认 → `/admin` |
| 直接访问（含登录后 `next` 回跳） | 登出 → `/admin/login` |

新建页首次自动保存成功后，地址换成 `/admin/posts/:id`（不刷新）。

**主按钮随状态变化**（US-08）：

| 文章状态 | 主按钮 | 设置抽屉里的"撤回为草稿" |
|---------|-------|-------------------|
| 草稿 | 发布 | 不显示 |

### 编辑区（左）

- **标题**：无边框大号输入框，占位"无标题"；回车把光标移到正文
- **工具栏**：二级标题、加粗、斜体、链接、行内代码、列表、任务列表、引用 | 插入图片（选文件）。全部为图标按钮（`IconButton/Ghost`），"插入图片"与格式按钮之间用竖线分隔。按钮在光标处插入/包裹 Markdown 语法；名称、快捷键、提示见下方"工具栏与悬停提示"（US-10）
- **源码区**：等宽字体，支持粘贴 / 拖入图片与实况照片（拖入时整个编辑区显示虚线描边 + "松开以上传图片或实况照片"）
- **上传占位**（US-05、US-11）：源码中先插入 `![处理中…]()`（HEIC 转换、实况视频转换、计算主色；普通 png/jpg/webp/gif 也要算主色，但很快），开始上传后变为 `![上传中…]()`，完成后替换为引用。"插入图片"的文件选择框接受 png、jpg、webp、gif、heic、heif、mov、mp4，可多选
- **底栏**：左"Markdown (GFM) · 支持粘贴/拖入图片 · 图片写法"（"图片写法"为文字按钮，见下方"图片写法说明"）；右字数（`tabular-nums`，不计空白的字符数，千分位）
- 已实现（Sprint 1）：`src/components/admin/editor/MarkdownEditor.tsx`——标题、源码区、底栏字数；底栏左侧在图片上传接入前只显示"Markdown (GFM)"

### 工具栏与悬停提示

提示用 `Tooltip`（底层 WarmTooltip，见 [components.md](../components.md)"悬停提示参数"，视觉见 [design-tokens.md](../design-tokens.md)"悬停提示"）。提示文字与按钮 `aria-label` 相同。

**工具栏**（一个 `TooltipGroup`；桌面提示在按钮下方，手机在按钮上方）：

| 按钮 | 作用 | 快捷键（Mac / 其他） | 手机 |
|------|------|------|------|
| 二级标题 | 行首切换 `## ` | — | ✓ |
| 加粗 | 包裹 `**` | `⌘B` / `Ctrl B` | ✓ |
| 斜体 | 包裹 `*` | `⌘I` / `Ctrl I` | — |
| 链接 | 变为 `[文字](url)`，选中 `url` | `⌘K` / `Ctrl K` | ✓ |
| 行内代码 | 包裹 `` ` `` | `⌘E` / `Ctrl E` | ✓ |
| 列表 | 行首切换 `- ` | `⇧⌘8` / `Ctrl Shift 8` | ✓ |
| 任务列表 | 行首切换 `- [ ] ` | — | — |
| 引用 | 行首切换 `> ` | `⇧⌘.` / `Ctrl Shift .` | ✓ |
| 插入图片 | 选文件上传（US-05） | — | ✓ |

- 快捷键只在焦点位于源码区时生效，拦截浏览器默认行为；输入法组字期间不触发
- 行级命令作用于选区覆盖的每一行；已有同样前缀时去掉，有其他前缀时替换
- 格式命令的改动能被 ⌘Z / Ctrl+Z 撤销（实现方式由 design-arch 定）
- 手机工具栏按钮按下时不让源码区失去焦点，避免键盘收起

**其他图标按钮**（单独的 `Tooltip`，提示都在按钮下方）：

| 按钮 | 提示 | 出现位置 |
|------|------|---------|
| 返回 | 返回文章列表 | 手机顶栏（桌面是"← 文章"文字按钮，不加提示） |
| 设置 | 文章设置 | 手机顶栏（桌面带文字，不加提示） |
| 关闭 | 关闭设置 | 设置抽屉 / 手机底部面板右上角 |

### 预览区（中）

- `surface` 底色，顶部小标签"预览"，其下以读者端 H1 样式显示文章标题；排版与读者端一致（衬线正文、Expressive Code 代码块）
- 并排模式下预览区比读者端窄，行宽不代表真实效果；要核对真实行宽切到"预览"模式（预览区内容最大宽度与读者端正文一致，约 680px）
- 正文停止输入后 300ms 内更新；与编辑区同步滚动（US-04-6）
- 渲染失败（US-04 BH-09）：保留上一次的预览内容，"预览"标签下方显示 `Alert/Error`"预览渲染失败，继续编辑会自动重试"；下一次渲染成功后提示消失（已实现，`MarkdownPreview.tsx`）
- 处理中 / 上传中的图片显示为占位块"图片处理中… 文件名" / "图片上传中… 文件名"（已实现：`src/lib/markdown/plugins/upload-placeholder.ts` + `MarkdownPreview`）
- 图片按读者端组件显示：`ArticleImage`（含宽图、图注、实况照片 `LiveBadge`）、`ImageGallery`（网格 / 手风琴），写法见 ADR-005；预览中点击图片不打开灯箱
- 输入时已加载的图片保持原状，不重复播放加载动画（US-12 BH-13）
- 已实现（Sprint 1）：Web Worker 渲染、读者端 H1 标题、文章区排版、空正文占位；视图切换、同步滚动、窄屏 Tab、图片组件在后续 Sprint

### 图片菜单（US-12）

预览中的单图和组图都有一个"图片选项"菜单，用来改写源码里的排版标记。组件 `ImageMenu`（见 [components.md](../components.md)）。

| 项 | 规则 |
|----|------|
| 触发按钮 | `OverlayButton`（`size` 32，图标 `ellipsis`，`aria-label`"图片选项" / "组图选项"），在图片或组图右上角内侧 8px；鼠标悬停在图片 / 组图上、或焦点进入时显示，平时隐藏（`opacity: 0`，仍可 Tab 聚焦）。组图内的单张图片不显示自己的按钮 |
| 打开 | 点击按钮，或聚焦后按 Enter / Space / ↓；菜单在按钮下方右对齐，空间不够时翻到上方 |
| 单图菜单 | `menuitemcheckbox`"宽图"（选中时右侧显示 ✓）。实况照片相同 |
| 组图菜单 | `menuitemradio`"网格" / "手风琴"（当前形态显示 ✓）→ 分隔线 → `menuitem`"拆成单图"。张数不在 3–7 时"手风琴"设为 `aria-disabled`，悬停 / 聚焦时提示"手风琴需要 3–7 张图片" |
| 执行 | 改写源码（与格式工具栏同一套写入方式，可 ⌘Z / Ctrl+Z 撤销）→ 预览重新渲染 → 菜单保持打开并停在原项，可以继续调整；"拆成单图"后组图消失，菜单关闭 |
| 关闭 | Esc、点菜单外、滚动预览区，或源码变化导致该图片在预览中消失 / 位置失效时关闭；关闭后焦点回到触发按钮（按钮已被移除时回到预览区） |
| 键盘 | 打开后焦点在第一项；↑ / ↓ 循环；Home / End；Space / Enter 执行 |
| 手机 | 点按图片或组图直接展开菜单（按钮同时显示），菜单项高 44px；点菜单外关闭；长按留给实况照片播放，不打开菜单 |
| 定位 | 按渲染时记录的源码位置 + URL 双重核对，核对不上时不改写并关闭菜单（US-12 BH-11） |

### 图片写法说明（US-12）

底栏"图片写法"打开一个浮层（`Popover`，非模态，`role="dialog"`，`aria-label`"图片写法"），位于按钮上方、左对齐，宽 360px，最高 60vh，超出时内部滚动。

| 区块 | 内容 |
|------|------|
| 写法示例 | 5 行，每行左侧说明，右侧是等宽字体示例 + 复制按钮（`IconButton/Ghost` `copy`，提示"复制"，复制后图标变 ✓ 1.5 秒）：宽图 `![](url#wide)`；实况照片 `![](url#live)`（"拖入同名照片和视频会自动生成"）；图注 `![](url "图注")`；组图网格"连续几行只放图片，中间不空行"；手风琴"组图第一张加 `#accordion`，3–7 张" |
| 从 iPhone 上传实况照片 | "iPhone 网页里从相册选择只能拿到静态图。"两种方法：① 电脑上"照片 → 文件 → 导出 → 导出未修改的原件"，把同名的 HEIC 和 MOV 一起拖进来；② iPhone 上先"存储到文件"，再用"插入图片"从"文件"里同时选中两个文件 |

打开时焦点移到浮层标题；Esc 或点外部关闭，焦点回到"图片写法"按钮。手机：入口放在设置底部面板最下方（文字按钮"图片写法"），点开后在面板内展开同样的内容，不另开浮层。

### 设置抽屉（右，宽 340px）

| 字段 | 控件 | 规则 |
|------|------|------|
| Slug（文章网址） | 等宽输入框 | 提示行实时显示 `/posts/{slug}`；未手动改过时跟随标题自动生成，改过后不再跟随（US-03-2/3）；中文标题生成失败时留空，提示"请填写英文 slug"；只允许小写字母、数字、连字符 |
| 标签 | 标签输入 | 回车加入为标签块，块上 × 删除；输入时下拉显示已有标签（自动补全） |
| 摘要 | 多行输入 | 右上角计数 `N / 200`，超过 200 计数变红且不可再输入；提示"留空时读者端自动截取正文开头" |
| 发布日期 | 日期选择 | 新建默认今天 |
| 撤回为草稿 | 次按钮 | 仅已发布时显示，点后弹确认框 |
| 删除文章 | 危险文字按钮 | 点后弹确认框；新建且从未保存过时不显示 |

抽屉默认：新建文章时**打开**（方便填信息），编辑已有文章时**关闭**。开合状态不跨文章记忆。

> 已实现（Sprint 1）：`src/components/admin/editor/PostSettingsDrawer.tsx`——Slug、摘要、发布日期；摘要按码位计数（与服务端一致）；标签、撤回已接入；删除在 Sprint 2。

## 保存状态（US-06）

| 状态 | 图标 + 文案 | 颜色 |
|------|-----------|------|
| 已保存 | ☁✓ 已保存 · HH:mm | ink-faint |
| 未保存 | ● 未保存 | ink-muted |
| 保存中 | ⟳ 保存中… | ink-faint |
| 保存失败 | ☁✕ 保存失败，将自动重试 | danger |

- 任何字段（标题、设置抽屉、正文）变化都触发自动保存，停止输入 2 秒后保存
- 已发布文章的自动保存只产生"未发布修改"，徽标切到"已发布 · 有未发布修改"
- 有未保存修改时离开页面 → 浏览器原生离开确认
- 保存时间使用 `tabular-nums`，避免数字变化时抖动
- 已实现（Sprint 1）：自动保存、保存状态、离开确认、Ctrl / ⌘ + S 立即保存；本地暂存与恢复横幅、401 跳转在 Sprint 2

| 名称 | 形式 | 内容 | 关联 |
|------|------|------|------|

| 实况照片错误 | 错误提示（danger，常驻） | "视频需要与同名照片一起拖入" / "无法读取 {文件名}，请换一张图片" / "上传失败，请重试"（带文件名） | US-11 |
| 实况照片降级 | 警示提示（warn，常驻，可关闭） | "实况视频超过 10MB，已作为普通图片插入" / "该实况视频在部分浏览器中只显示静态图"；带文件名 | US-11 |
| 操作成功 | 轻提示（ok，4 秒消失） | 发布："已发布，几分钟后读者可见"；发布更新："已发布更新"；撤回："已撤回为草稿" | US-08 |

提示条出现在页面底部居中：成功类 4 秒后自动消失（`role="status"`）；错误类和警示类带 × 关闭按钮，常驻到用户关闭或重新操作（错误类 `role="alert"`，警示类 `role="status"`）。

| < 768px | 顶栏：返回图标、保存状态、设置图标按钮、主按钮（图标按钮可点区域 44×44）；视图切换换成顶栏下方的"编辑 / 预览"两个 Tab（`role="tablist"`，US-04-5）；工具栏固定在底部（键盘上方），图标精简为 H、B、链接、代码、列表、引用、插入图片，每个可点区域 44×44，长按 500ms 显示提示（在按钮上方、不显示快捷键）；设置改为底部弹出面板（最下方有"图片写法"）；编辑区底栏隐藏；预览中点按图片直接展开图片菜单；标题、源码区等所有输入框字号 16px（防 iOS 自动放大） |

## 数据需求

| 操作 | 触发 | 说明 |

| 读取文章 | 进入编辑页 | 返回最新保存内容（含未发布修改）与状态 |

## 原型

- Pencil：[admin.pen](../admin.pen)

  - `04 状态与弹层`：删除/撤回确认、本地恢复横幅、保存状态、主按钮变体、校验与错误提示、警示提示（`Toast/Warning`）
