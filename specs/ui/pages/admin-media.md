# 书影音条目（Admin Media）

**路由**: 列表 `/admin/media?type={分类}`（缺省 `book`）；新增 `/admin/media/new?type={分类}`；编辑 `/admin/media/:id`
**状态**: draft
**关联**: F-005 · US-01、US-02、US-04 · [Backlog](../../backlog/media-douban-sync.md)

## 页面用途

作者维护书影音条目：按分类查看全部条目（含隐藏），新增、编辑、隐藏、删除；录入表单顶部粘贴豆瓣分享内容自动填好条目信息。

## 入口与出口

| 从哪来 | 去哪里 |
|--------|--------|
| 后台顶栏"书影音"（`AdminHeader current="media"`） | 列表"新增条目" → `/admin/media/new?type=当前分类` |
| 直接访问（未登录 → `/admin/login?next=原路径`） | 列表行"编辑" / 手机点行 → `/admin/media/:id` |
| 表单"← 书影音" / "取消" / 保存成功 | `/admin/media?type=条目分类` |
| 识别到重复条目 → "去编辑" | `/admin/media/:id`（已有条目） |
| 列表"从豆瓣导入" | 本页弹窗 `DoubanImportDialog`，关闭后留在列表 |

| 错误 | `Alert/Error`：找不到用户 / 未公开或需登录 / 豆瓣暂时无法访问（后者若已导入部分条目，同时显示汇总）；按钮回到打开时的样子 |

- 结束（完成、停止、中途出错）且有写入时，前端调用一次"结束"接口触发重建，并 `Toast/Success`"读者页将在重建后更新"
- 手机：弹窗左右 16px 全宽、按钮全宽各占一半；无单独设计稿
- 可访问性：`role="dialog"` `aria-labelledby` 指向标题；打开时焦点到 ID 输入框；关闭后焦点回到"从豆瓣导入"按钮；错误用 `role="alert"`

### RecognizeBox

| 部分 | 规则 |
|------|------|
| 标签 | 输入框上方"豆瓣分享内容"，13px 600 `ink`（即 `<label>`） |
| 输入 | 框：`bg` 底、`input-border` 描边、圆角 12，轻投影与悬停光晕同 `Field`；多行文本，2 行高（手机 16px 字号），占位"粘贴豆瓣分享链接或分享文字，自动识别条目信息"；粘贴不触发识别 |
| 底栏 | 框内右下：清空 `IconButton/Ghost` ✕（有内容时显示，点后清空并聚焦输入）、`Button/Secondary`"识别"（`scan-text`）；内容为空白时"识别"禁用 |
| 可识别类型 | 输入框下一行 6 个小卡片，宽度随文字、间距 6（`surface` 底、`line` 描边、圆角 8、内边距 6 10，13px 图标 `ink-faint` + 12px `ink-muted`）：`book-open` 书、`book-image` 漫画、`clapperboard` 电影、`tv` 剧集、`gamepad-2` 游戏、`dices` 桌游；只作说明，不可点；手机隐藏 |
| 结果卡 | 结果区是一张卡片（`surface` 底、`line` 描边、圆角 12、内边距 12），无结果时不显示。成功 / 重复时顶部是预览行：缩略图 32×48（圆角 3，封面没识别到时 `surface-sunken` 空底）+ 标题 14px 600 `ink` + "分类 · 作者 · 年份" 12px `ink-faint`（重复时末尾加"· 已录入"）；下面是结果行。失败时没有预览行 |

| 重复 | 结果区 `copy`（`warn`）"这条已经录入过：《标题》 · 读过 2026-10-01"，下方 `accent` 文字链接"去编辑 →"；表单不变。表单有未保存改动时点"去编辑"先弹 `ConfirmDialog/Default`"放弃当前填写的内容？"（"继续填写" / "放弃并前往"） |

| 播报 | 结果区 `role="status"`（失败也用 `status`，不打断输入） |

### StarRating

5 颗表情星（36×34，间距 16，手机同尺寸），累计点亮前 N 颗（黄色实心、各带深色表情），其余灰色占位，表情从难过到开心随分值变化；右侧"N / 5"（`font-mono` 12px `ink-faint`，未评分时"未评分"）；不设"清除"按钮，再点当前星取消评分。切换时高光从旧星滑到新星，参数见 [components.md](../components.md)"评分动效参数"。键盘：`role="radiogroup"`，每颗星 `role="radio"` `aria-label="N 星"`，左右方向键改值。不做悬停预览（原作没有，且与滑动动效冲突）。

### 校验与保存

| 情况 | 表现 |
|------|------|
| 前端校验（标题空白、年份非 4 位数字） | 不发请求；`Field` 错误态 + 字段下提示（"请填写标题" / "年份为 4 位数字"）；焦点移到第一个出错字段 |
| 封面文件不合规 | 选择文件后立即提示 `Field` 错误"封面只支持 jpg / png / webp，且不超过 5 MB"，保留原封面 |
| IGDB 链接格式不对（游戏） | 前端校验，不发请求；封面链接 `Field` 错误"请粘贴 images.igdb.com 的封面图片地址"；预览为虚线占位 |
| IGDB 链接打不开（游戏，422 `COVER_LINK_UNREACHABLE`） | 封面链接 `Field` 错误"封面链接打不开，请检查后重试"，焦点移到该字段，表单保持 |
| 保存中 | "保存"加载并禁用，防重复提交；表单可见不锁定 |
| 成功 | 回列表（条目分类），`Toast/Success`"已保存，读者页将在重建后更新" |
| 服务端校验失败（400） | 对应字段错误态，表单保持 |
| 失败（5xx / 网络） | `Toast/Error`"保存失败，请重试"，表单内容不丢 |
| 离开有改动的表单 | 浏览器 `beforeunload` 确认；"取消" / "← 书影音"点后先弹 `ConfirmDialog/Default`"放弃未保存的改动？" |
