# 首页（Reader Home）

**路由**: `/`
**状态**: draft
**关联**: F-002 · US-02 · 设计稿 [admin.pen](../admin.pen) 06 / 06m · 外壳见 [reader-shell.md](reader-shell.md)

## 页面用途

自我介绍：读者了解作者是谁、写什么、怎么联系。不列文章（文章在 `/posts`）。

## 入口与出口

| 从哪来 | 去哪里 |
|--------|--------|
| 直接访问、顶栏站点名、各页 `> cd ..`、404"回首页" | 顶栏"文章" → `/posts`；社交链接（新标签页）；邮箱 `mailto:` |

## 布局 `HomeIntro`

主体居中，宽 640px（手机左右 20px），上下留白 96 / 120（手机 48 / 64）。纵向依次：

| 区域 | 内容 |
|------|------|
| 头像 | 96×96 圆形（手机 64，与问候语同行）；`alt="{名字} 的头像"`；带 `width` / `height` |
| 问候语 | "你好，我是 {名字}"，`text-display` 600 |
| 简介 | 第一段 `ink`，其余段 `ink-muted`；16px，行高 1.7，段间 16px；段数不限 |
| 链接行 | 图标 14px `ink-faint` + 文字 14px `ink-muted`，间距 20px：GitHub、摄影、邮箱（文字为邮箱地址）；悬停 `accent` + 底边线；手机可点高度 44px |

> 已实现（Sprint 4，add-home-intro）：`src/pages/index.astro`、`src/components/reader/HomeIntro.astro`；占位头像 `public/avatar.png`（192×192 渐变，作者提供真实头像后替换）。

## 内容来源 `src/config/site.ts`

| 字段 | 类型 | 规则 |
|------|------|------|
| `name` | 字符串 | 必填；用于问候语、头像 alt |
| `avatar` | 站内路径 | 必填；放在 `public/` |
| `bio` | 字符串数组 | 至少 1 段 |
| `github` / `photo` | http(s) URL 或空 | 空则首页与顶栏都不显示该链接 |
| `email` | 邮箱或空 | 空则不显示 |

配置在构建时校验（`normalizeSiteConfig`），不合法则构建失败并指出字段名；改配置并推送即重建生效。开发阶段使用占位内容，真实文案由作者提供。

## 页面状态

静态页，无加载 / 错误态。所有可选链接为空时链接行不渲染。
