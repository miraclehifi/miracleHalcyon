# 文章列表（Admin Post List）

**路由**: `/admin`（查询参数 `?status=draft|published&q=关键字&page=2`）
**状态**: draft
**关联**: F-001 · US-02、US-07、US-09 · [Backlog](../../backlog/swipe-row-actions.md)

## 页面用途

后台首页：找到要继续写或修改的文章，或新建一篇。

## 入口与出口

| 从哪来 | 去哪里 |
|--------|--------|
| 登录成功 | 点击文章 → `/admin/posts/:id` |
| 写文章页"← 文章"、删除文章后 | "新建文章" / "写第一篇" → `/admin/posts/new` |
| 后台顶栏站点名 | "查看博客" → `/`（新标签页）；"登出" → `/admin/login` |

## 布局

- **顶栏**（全宽，下边框）：左"miracleHalcyon 后台"；右"查看博客""登出"（文字按钮）
- **主体**（居中，宽 896px，与读者端文章列表 `/posts` 同宽）：
  1. 标题行：衬线大标题"文章" + "共 N 篇"；右侧主按钮"新建文章"
  2. 筛选行：左侧分段控件"全部 / 草稿 / 已发布"（每项带数量）；右侧"搜索标题"输入框
  3. 列表：卡片纵向排列，间距 20px，外框样式与读者端 `PostCard` 一致（见 [components.md](../components.md)），内容只有标题、状态、更新时间和编辑 / 删除按钮
  4. 分页：左"第 1–20 篇，共 23 篇"，右"上一页 1 2 下一页"

### 列表行

| 区域 | 内容 |
|------|------|
| 卡片 | 内边距 20px 28px，圆角 12px，1px 虚线边框 `line-strong`，底色 `bg`，与读者端 `PostCard` 同一套外框；高 96px |
| 左（占满） | 标题 20px 粗体，单行超出省略；下一行：状态徽标（草稿 / 已发布 / 已发布 · 有未发布修改，配色见 [design-tokens.md](../design-tokens.md)"文章状态配色"）+ "更新于 {相对时间}"（12px `ink-faint`） |
| 右 | "更多操作"按钮 `⋯`（`IconButton/Ghost`，32×32，图标 16px），见"行操作" |

只展示标题、状态、更新时间；不显示摘要、封面、标签。编辑、删除收在左滑抽屉里。

- 标题为空的草稿显示斜体浅色"无标题"
- 更新时间：1 小时内"N 分钟前"，当天"今天 HH:mm"，今年"M月D日"，更早"YYYY-MM-DD"（不足 1 分钟显示"1 分钟前"；已实现：`src/lib/format/relative-time.ts`）
- **结构**：标题是 `<a href="/admin/posts/:id">`，用伪元素把它的可点区域扩到整行；`⋯` 是和链接并列的 `<button>`（叠在伪元素之上），不嵌套在链接里。整行可点，键盘 Tab 顺序是"标题 → 更多操作"（抽屉打开时再到"编辑 → 删除"）
- 悬停 / 键盘聚焦时与读者端 `PostCard/Hover` 相同：双层虚线错位，边框保持 `line-strong`；同时显示 `⋯`。开始拖动或抽屉打开时双层错位收回
- **入场与选中**（列表底层 AnimatedList，参数见 [components.md](../components.md)"列表动效参数"；已实现，Sprint 2）：
  - 进入页面、筛选、搜索、翻页后，卡片逐行弹入（错开 50ms）；减弱动效时只渐显
  - 同一时间只有一张卡片处于悬停态：鼠标移到哪张就是哪张，移出列表后复原；键盘焦点进入某张卡片（标题、`⋯`、编辑或删除）时该卡片进入悬停态
  - 焦点在列表内时，↑ / ↓ 把焦点移到上一张 / 下一张卡片的标题，Home / End 到第一张 / 最后一张，到头不循环；焦点不在列表内时方向键照常滚动页面；Tab 顺序不变

### 行操作

每行底层是 React Bits SwipeRow（参数见 [components.md](../components.md)"行滑动参数"）。桌面、手机同一套。

| 项 | 规则 |
|----|------|
| 抽屉 | 卡片向左移开后，右侧露出两格，每格 80px：内侧"编辑"（square-pen，`surface-sunken` 底、`ink` 字）、外侧"删除"（trash-2，`danger` 底、`danger-ink` 字）；图标 20px，下方 11px 文字 |
| 打开 | 手指或鼠标按住卡片向左拖（水平移动超过 10px 且大于竖直移动才算拖动，否则交给页面滚动）；松手时露出过半或快速左甩即停在打开位置，否则弹回。也可以点 `⋯` 打开 |
| 全滑删除 | 拖过行宽 60% 时，红色删除块向左跃出铺满整行（触屏轻振一次），读屏播报"松手删除"；此时松手即删除；往回拖则缩回抽屉 |
| 收起 | 往右拖、点卡片、再点 `⋯`、按 Esc、打开另一行、筛选 / 搜索 / 翻页时收起；同一时间只有一行抽屉打开 |
| 编辑 | `<a href="/admin/posts/:id">`，与点卡片去同一个地方 |
| 删除 | 点"删除"与全滑相同，见下方"删除与撤销"；列表里不弹确认框 |
| 不误跳转 | 拖动过的那次松手不触发卡片链接；抽屉打开时点卡片只收起 |
| `⋯` 显隐 | 桌面卡片悬停或自身聚焦时显示，图标 `ink-faint`，按钮悬停底色 `surface-sunken`、图标 `ink`；手机平时不显示（用滑动），获得键盘 / 读屏焦点时显示。`aria-label="《{标题}》的操作"`、`aria-expanded` 指示抽屉开合 |
| 键盘 | 焦点在 `⋯` 上：Enter / Space / ← 打开，焦点移到"编辑"；→ / Esc 收起，焦点回到 `⋯`；抽屉打开时 Delete / Backspace 直接删除 |
| 动效 | 松手回位用弹簧（0.3s，无回弹）；快速甩动带 0.2 回弹；跃出块弹簧 0.3s；删除后行高度折叠到 0（200ms）。`prefers-reduced-motion` 时位移 0.2s ease-out、无回弹无跃出动画 |
| 防误触 | 拖动中卡片 `user-select: none`、`-webkit-touch-callout: none`；标题链接 `draggable="false"` |

### 删除与撤销

| 项 | 规则 |
|----|------|
| 移除 | 行折叠消失，"共 N 篇"和筛选数量立即减 1 |
| 提示 | 底部居中 `Toast/Undo`："已删除《标题》"+ 文字按钮"撤销"，6 秒后消失；鼠标悬停或焦点在提示上时暂停计时；`role="status"` |
| 撤销 | 点"撤销"（或提示聚焦时按 Ctrl/⌘+Z）：该行按原位置插回并单行弹入，数量恢复，不发删除请求 |
| 提交 | 提示消失时才发删除请求；离开页面（跳转、关标签）时立即发出；连续删除第二篇时，先提交第一篇，提示换成第二篇 |
| 补位 | 提交成功后重新拉取当前页补齐 20 篇；当前页删空时回到上一页；全部删完显示空状态 |
| 失败 | 行按原位置插回，常驻错误提示"删除《标题》失败，请重试" |
| 写文章页 | 设置抽屉里的"删除文章"仍弹确认框（见 [admin-post-editor.md](admin-post-editor.md)"弹层"），不走撤销 |

|------|------|------|
| 新建文章 | 主按钮 | 跳转 `/admin/posts/new` |

| 行操作抽屉 | SwipeRow | 编辑 / 删除，见"行操作" |
| 撤销提示 | `Toast/Undo` | 见"删除与撤销" |
| 分页 | 分页器 | 每页 20 篇；只有 1 页时隐藏 |

## 页面状态

> 已实现（Sprint 1 主干，build-post-list-page）：`src/pages/admin/index.astro`（SSR 首屏）+ `src/components/admin/PostListPage.tsx`——默认、加载中骨架、错误重试；状态筛选、标题搜索、分页、两种空态已接入（URL 解析 `src/lib/admin/list-query.ts`；搜索用 `replaceState`）。行操作、删除与撤销、入场动效在 Sprint 2。

| 状态 | 表现 |
|------|------|
| 默认 | 按更新时间倒序 |
| 加载中 | 列表区显示 5 行骨架；筛选/翻页时保留旧列表并降低不透明度 |
| 空（无任何文章） | 隐藏筛选行和分页；居中显示羽毛图标、"还没有文章"、"写下第一篇，草稿会自动保存"、主按钮"写第一篇" |
| 筛选无结果 | 列表区写明条件：有关键字时"没有标题包含"{关键字}"的{草稿/已发布}文章"，只有状态筛选时"还没有{草稿/已发布}文章"；下方文字按钮"清除筛选" |
| 错误 | 列表区显示"加载失败"+"重试" |
| 删除后 6 秒内 | 该行已移除，底部撤销提示，数量已减 1（见"删除与撤销"） |

## 数据需求

| 操作 | 触发 | 说明 |
|------|------|------|
| 查询文章列表 | 进入页面、筛选、搜索、翻页 | 返回标题、状态（含是否有未发布修改）、更新时间，以及各状态数量 |
| 删除文章 | 撤销提示消失或离开页面时 | 请求需在页面卸载时也能发出（keepalive）；成功后重新拉取当前页 |
