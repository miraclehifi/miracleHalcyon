# 书影音（Reader Media）

**路由**: `/media`（书）、`/media/:type`（`comic` / `movie` / `series` / `game` / `boardgame`）
**状态**: draft（已实现：Sprint 9 任务 8 页面与书、漫画、桌游，任务 10 电影、剧集海报墙；游戏海报墙待实现，[game-case-shelf](../../backlog/game-case-shelf.md)）
**关联**: F-005 · US-03 · [Backlog](../../backlog/media-douban-sync.md)

## 页面用途

读者按分类浏览作者读过、看过、玩过以及正在进行的条目。只读、构建时预渲染，参考 [pseudoyu · Media](https://www.pseudoyu.com/media?type=book)。

## 路由决定

| 项 | 决定 | 理由 |
|----|------|------|
| 分类切换 | 每个分类一个预渲染页：`/media` = 书，其余 `/media/{type}`；分类标签是链接，由 `MediaTypeTabs` 岛（GooeyNav）播完水滴动画后整页跳转，无 JS 时是普通链接 | 每页只含一个分类的条目，HTML 体积随分类拆开；可直接分享分类地址；React 岛只有分类导航与电影、剧集、游戏的海报墙（2026-10-22 [gooey-media-tabs](../../backlog/gooey-media-tabs.md)、[media-poster-wall](../../backlog/media-poster-wall.md)，原为零 JS） |
| `/media/book` | 不生成，`/media` 即书 | 避免同一内容两个地址 |
| 未知分类（如 `/media/music`） | 站点 404 页 | 静态路由，未生成即 404（US-03 BH-14 取路径路由分支） |
| 分页 | 不做 | 单分类数百条量级；封面 `loading="lazy"` |
| 按时间分段 | 只用于电影、剧集、游戏海报墙，由读者用"按时间"按钮开关，默认关闭；分段在浏览器按当天日期计算，不写进 URL | 页面构建时预渲染，构建时写死"本月 / 上个月"会过期；其他分类条目少、形态不同，不做 |

## 入口与出口

| 从哪来 | 去哪里 |
|--------|--------|

### 排序

进行中的条目在前；同组内按标记日期倒序；同日按创建时间倒序。海报墙不分段时同此顺序；分段时段内同此顺序。

### 海报墙（电影、剧集；游戏的差异见下一节）

参数见 [components.md](../components.md)"海报墙参数"。

| 项 | 表现 |
|----|------|
| 排布 | Masonry 等宽列，海报统一 2:3，间距 16；容器宽 < 600px 时 2 列，否则按列宽 200 自动（1440 宽 6 列）；滚到时自下而上依次弹入（模糊转清晰） |
| 正面 | 只有封面，不显示"在看"等徽标 |
| 悬停 | 海报朝指针轻微倾斜、放大 1.02，跟随指针的反光；底部浮出片名（只有片名，样式同 Masonry caption）。键盘聚焦时同样浮出片名；触屏无悬停 |
| 翻面 | 点击、Enter 或空格：海报绕 Y 轴翻到背面——片名、评分、短评、"看过 · 2026-10-14"（手机只显示日期；进行中为"在看"徽标）；**不显示导演**。再点翻回。同一时间只翻开一张，翻另一张时前一张自动翻回；Esc 翻回 |
| 背面底色 | 亮色白底、暗色 `#27272A` 底（令牌 `flip-surface` / `flip-ink`，同 FlipCard 示例） |
| 豆瓣链接 | 只在背面右下角出现"豆瓣 ↗"（新标签页）；正面不可点、不可聚焦；无豆瓣链接不显示。整张海报不再是链接（点击用于翻面） |
| 无封面 / 加载失败 | 正面为占位底 + 图标 + 片名，悬停不再浮出片名，仍可翻面 |
| 无 JS | 静态网格（不分段）只显示海报正面，不能翻面；"豆瓣 ↗"固定显示在海报右下角；没有"按时间"按钮 |
| 减弱动效 | 无入场位移与模糊；翻面直接切换，无旋转；悬停片名只淡入 |

### 游戏海报墙（设计稿 09f，组件区"读者端区块" Row 7）

版式、翻面、按时间分段、无 JS 兜底、减弱动效都同上方"海报墙"，只有下表不同：

| 项 | 游戏 |
|----|------|
| 封面来源 | IGDB 大图外链 `https://images.igdb.com/igdb/image/upload/t_1080p/{图片ID}.jpg`（[ADR-013](../../engineering/features/F-005-书影音/architecture/adr/ADR-013-game-cover-igdb-link.md)） |
| 砖块比例 | **与大图实际宽高比一致**（`aspect-ratio: {coverWidth} / {coverHeight}`，宽高在录入保存时读取），列宽不变、高度随比例变化，Masonry 各列自然错落；图片 `object-fit: contain` 兜底，**不裁切**；`<img>` 带 `width` / `height` 属性防布局跳动 |
| 正面悬停 / 键盘聚焦 | **不浮出游戏名**、不加底部渐变；左下角（距左 10、距底 10）淡入 `PlatformBadge`（PS5 / PS4 / Switch / Switch 2 / Steam），0.2s；倾斜与反光同电影 |
| 翻面交互 | 同电影：点击、Enter 或空格绕 Y 轴翻到背面（0.6s），再点 / Esc 翻回；同一时间只翻开一张；减弱动效时直接切换。设计稿：组件区 Row 7"游戏卡片翻面交互"（① 默认 → ② 悬停显示平台 → ③ 翻转中 → ④ 背面）、09f 中"黑神话：悟空"为翻开态 |
| 背面 | 与正面同尺寸（高度随封面比例）；游戏名（15px 600，最多 2 行）→ `PlatformBadge`（间距 8）→ 评分 → 短评（占满剩余高度后省略）→ 底部"玩过 · 2025-08-20"（进行中为"在玩"徽标）与"豆瓣 ↗"；**不显示开发商**（同电影不显示导演） |
| 触屏（`hover: none`） | 正面不显示平台；平台只在背面 |
| 无封面 | 砖块按 3:4；占位底 + `image-off` + 游戏名；悬停仍显示平台 |
| 封面加载失败 | 砖块保持记录的宽高比不跳动，切换为同样的占位 |

### 按时间分段（设计稿 09d、09d-s）

读者点 `MediaTimeToggle`（"按时间"）开关：关闭（默认）时整面墙不分段；打开时按下表分段，每段一个 `MediaTimeHeading` + 一面 Masonry 墙。选择记在浏览器里，下次打开沿用；读不到时按关闭。切换时已翻开的海报翻回。

以浏览器当天本地日期 `today` 为准，条目依次落入第一个满足的段（标记日期 = `markedOn`）：

| 段 | 条件 | 标题 meta（示例：today = 2026-10-22） |
|----|------|------|
| 在看 | `status = in_progress`（不论日期） | `1 部` |
| 本月 | 与 `today` 同年同月；以及晚于 `today` 的日期 | `10 月 · 3 部` |
| 上个月 | `today` 的上一个日历月（1 月时为上一年 12 月，归这里而不是"去年"） | `9 月 · 2 部` |
| 本年 | 与 `today` 同年的其余月份 | `2026 · 7 部` |
| 去年 | `today` 年份 − 1 的其余月份 | `2025 · 6 部` |
| 四位年份（如 `2024`） | 更早，每年一段，倒序 | `3 部` |

- 没有条目的段不显示；量词随分类（电影、剧集"部"，游戏"款"）；游戏的进行中段标题为"在玩"
- 分段标题 `position: sticky; top: 0`（顶栏不吸顶），下缘 56px GradualBlur：海报滚到标题下方时逐渐模糊并淡入页面底色（09d-s）；GradualBlur 只在标题吸顶时出现，未吸顶时第一排海报保持清晰（09d）
- 分段标题为 `<h2>`，段与段间距 28，标题与海报间距 16

### 条目（字段与样式见 [components.md](../components.md) `MediaCard` / `MediaRow`）

| 情况 | 表现 |
|------|------|
| 有豆瓣链接 | 整卡 / 整行为 `<a target="_blank" rel="noopener noreferrer">`，卡片底部显示"豆瓣 ↗"（海报墙例外，见上） |
| 无豆瓣链接 | 不是链接、无手型指针、无"豆瓣 ↗"；卡片悬停不放大封面 |
| 进行中 | 标题后"在读 / 在看 / 在玩"徽标（`accent-soft` 底）；卡片底部用徽标代替"读过 · 日期"（海报墙正面不显示徽标，见上） |
| 无评分 | 不渲染星级；`MediaRow` 保留评分列宽 88 以对齐后面的年月列 |
| 无封面 / 加载失败 | `surface-sunken` 底 + `image-off` 图标，`role="img"` `aria-label="图片不可用"`；加载失败用 `<img onerror>` 的一行内联处理切换（不引入框架） |
| 封面裁切 | 书、漫画、电影、剧集、桌游统一 2:3 `object-fit: cover` 居中裁切；**游戏不裁切**，按原比例（见"游戏海报墙"） |
| 标记日期 | 卡片底部 `yyyy-MM`（"读过 · 2026-10"）；列表行右侧 `yyyy-MM`（`font-mono` 12px）；海报背面 `yyyy-MM-dd` |
| 标题 | 卡片单行省略；列表行单行省略；海报背面最多 2 行 |
| 短评（卡片、海报背面） | 保留换行；卡片最多 4 行省略，海报背面占满剩余高度后省略；纯文本转义 |

封面地址为站内 R2 路径，**游戏除外**（IGDB 外链）；页面不请求任何豆瓣域名资源。

## 可访问性

- 分类导航 `<nav aria-label="书影音分类">`，当前项 `aria-current="page"`
- 列表为 `<ul>`，每项 `<li>`；星级用 `StarRating/Small`（只读，`role="img"` `aria-label="评分 N / 5"`，星形 SVG `aria-hidden`）
- 海报墙为 `role="list"`，每张海报 `role="listitem"`；翻面控件为 FlipCard 的 `role="button"`（`aria-label="《片名》"`、`aria-pressed` 表示是否翻开），未显示的一面 `aria-hidden`；悬停片名 `aria-hidden`（名称已在控件上）；"豆瓣 ↗"是控件外的兄弟链接，未翻开时 `tabIndex=-1`
- "按时间"为 `<button aria-pressed>`；分段标题为 `<h2>`，读屏可按标题跳段
- 平台徽标 `aria-label="平台：PS5"` 等；正面徽标为悬停装饰（`aria-hidden`，名称与平台已在翻面控件的 `aria-label="《游戏名》，PS5"` 上），背面徽标正常朗读
- 外链文字含标题（`aria-label="在豆瓣查看《片名》（新标签页）"`）
