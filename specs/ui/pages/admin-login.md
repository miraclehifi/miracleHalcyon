# 登录页（Admin Login）

**路由**: `/admin/login`（可带 `?next=/admin/...`）
**状态**: draft
**关联**: F-001 · US-01

## 页面用途

作者输入账号密码进入后台。

## 入口与出口

| 从哪来 | 去哪里 |
|--------|--------|
| 未登录访问任意 `/admin/**` | 登录成功 → `next` 指向的页面；无 `next` → `/admin` |
| 后台点击"登出" | "← 返回博客首页" → `/` |
| 直接访问 | 已登录且会话有效 → 直接跳转 `/admin` |

## 布局

整页纸色底，内容是一列居中、宽 360px 的竖排，不包卡片：

1. 站点名 `miracleHalcyon`（`font-body` `text-display` 32px，字重 600）+ 副标题"作者后台 · 请登录后继续"（`text-ui`，`ink-muted`）
2. 错误提示条（仅出错时显示）
3. 表单：账号、密码、登录按钮（主按钮，占满整行）
4. "← 返回博客首页"文字链接

## 组件清单

| 组件 | 类型 | 说明 |
|------|------|------|
| 账号 | 文本输入框 | `autocomplete="username"`，自动聚焦 |
| 密码 | 密码输入框 | `autocomplete="current-password"`，回车提交 |
| 登录 | 主按钮 | 账号或密码为空时禁用（BH-05）；提交中显示"登录中…"并禁用 |
| 错误提示条 | 提示条（danger-soft） | 显示服务端返回的错误文案 |

## 页面状态

| 状态 | 表现 |
|------|------|
| 默认 | 无错误提示条，账号框已聚焦 |
| 提交中 | 按钮显示"登录中…"并禁用，输入框只读 |
| 凭据错误 | 提示条："账号或密码错误，请检查后重试"；清空密码框，保留账号 |
| 限流 | 提示条："尝试次数过多，请 15 分钟后再试"；按钮保持可点（由服务端拒绝） |
| 网络错误 | 提示条："网络异常，请重试" |
| 空字段 | "登录"按钮禁用，不发请求（BH-05 / TC-US01-29、30）；浏览器自动填充或水合前已输入的值在挂载时同步，不会误判为空 |

错误提示条使用 `role="alert"`；提交失败后焦点回到密码框。

## 响应式

| 断点 | 变化 |
|------|------|
| ≥ 768px | 内容在视口中垂直居中 |
| < 768px | 列宽改为 100% − 32px 边距，顶部对齐（上方留 20vh）；输入框字号 16px（防 iOS 自动放大），按钮高度 ≥ 44px |

## 数据需求

| 操作 | 触发 | 说明 |
|------|------|------|
| 登录 | 提交表单 | 成功下发 HttpOnly/Secure/SameSite=Lax 会话 Cookie；失败按错误类型返回提示（具体接口由 design-domain 定义） |
